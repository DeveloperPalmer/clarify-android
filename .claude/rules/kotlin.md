# Kotlin

## Один класс — один файл

Несколько классов в одном файле не складываем. Вспомогательный `data class` рядом с основным классом
уезжает в собственный файл в соседний пакет `entity`, а не в хвост файла после закрывающей скобки.

**Почему:** класс, дописанный внизу чужого файла, не находится ни поиском по имени файла, ни
навигацией по дереву — его видит только тот, кто уже открыл этот конкретный файл.

- Файл называется по классу; `private data class` при выносе становится `internal`.
- Правило про **классы**. Приватные top-level константы остаются в файле, где используются.
- Исключение — `Mocks.kt`: моки собираются вместе намеренно.

## Expression body запрещён у функций

```kotlin
// нельзя
private fun MessageChipState.toIconResId(): Int? = when (this) { … }

// нужно
private fun MessageChipState.toIconResId(): Int? {
  return when (this) { … }
}
```

**Почему:** `return` показывает, что именно функция отдаёт, — на длинном `when` или цепочке вызовов
это не видно из первой строки.

Два исключения:

- **`val` правило не затрагивает.** `get() = nodes.isEmpty()` остаётся как есть.
- **Функция, тело которой целиком лямбда-билдер**, — блок у неё уже есть, и `return` добавил бы
  только уровень вложенности:
  ```kotlin
  override fun buildMachine(): Machine<ViewState> = machine {
    initial = ViewState() to null
    …
  }
  ```

## Мапперы — в пакет `mapper`

Преобразование одного представления в другое не пишется по месту: ни лямбдой внутри другого маппера,
ни конструктором в репозитории, ни приватной функцией в хвосте файла компонента.

- **Место:** пакет `mapper` того модуля, где маппер нужен — `feature/<name>/ui/…/ui/mapper`,
  `feature/<name>/data/…/data/mapper`. Межслойные модели общего пользования — в модуле `mapper/*`.
- **Файл:** `<Источник>Mappers.kt` — по типу, с которого маппинг начинается.
- **Имя по направлению**, а не выбирается заново каждый раз: в доменную модель — `toDomainModel()`,
  в сетевую — `toNetworkModel()`, в остальных случаях — `to<Результат>()`. Заводить `toDomain`,
  `mapToX`, `toXParams` нельзя, пока пара слоёв покрывается существующей парой.
- **Расширение на исходном типе.** Контекст, которого в исходном типе нет (id текущего пользователя,
  идентификатор родителя), передаётся параметром.
- Имя обязано соответствовать результату: функция, отдающая строку кэша, `toDomainModel()`
  называться не может.

**Почему:** одинаковые имена делают направление понятным по вызову, без чтения тела. Вынесенный
маппер переиспользуется, а лямбды внутри других мапперов разрастаются и расползаются копиями по
репозиториям.

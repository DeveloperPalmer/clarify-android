## Назначение
Wiki проекта — структурированая база знаний. Claude ведёт wiki, человек направляет.

## Структура
```
raw/            — инбокс необработанных экспортов (после обработки пуст)
raw/recycled/   — архив обработанных снапшотов; самый свежий = текущий канон
wiki/index.md   — оглавление
wiki/log.md     — append-only журнал операций
wiki/feature/   — фича, описанная с позиции бизнес-аналитика
wiki/method/    — API-методы. Источник API — OpenAPI-спека; пока её нет — Firestore.kt
```

## Категории и граф
Граф: `feature → method`. Направление строгое.

## Теги
Только во frontmatter, без inline-тегов. Каждая страница несёт ровно один тег категории по папке.
- `feature` / `method` — по папке
- `stub` — единственный признак заглушки; снимается только явным удалением тега
- `root` — системные файлы (CLAUDE.md, index.md, log.md); без тегов категории
Frontmatter: теги без `#`. Поиск: `tag:#method`, `tag:#stub`.

## Ответы на вопросы
1. Читать `wiki/index.md` → найти релевантные страницы.
2. Противоречие между источниками — указать явно. Утверждение без источника — пометить как требующее проверки.

## Lint
- Противоречия между страницами.
- Каждый файл wiki описан в `index.md` через `[name](path.md)`, не `[[wikilinks]]`.
- Изоляция методов: в `wiki/method/` запрещены `[[wikilinks]]`, `[name](path.md)`.
- **Req**: `Y` / `N`. Никаких `Yes`/`No`.
- **Enum в Description**: вертикально через `<br>\* value` строчными буквами.
- **Enum в JSON**: значения строчными (`"open"`, не `"Open"`).
- **JSON**: вложенные объекты раскрыты полностью, nullable-поля показывать явно (`"mergedAt": null`).
- **Wrapper-типы в Request**: разворачивать до строки (`Peer.Id("x")` → `"x"`).

## Rules
- Язык: позиция бизнес-аналитика — что делает продукт, деталей реализации кода запрещены, при конфликте спросить.
- **Никаких ссылок на файлы.** CLAUDE.md запрещено содержать markdown-ссылок `[...](...)`.
- **Циклы запрещены.** Между страницами нет взаимных ссылок. Если A ссылается на B, то B не ссылается на A, транзитивные циклы A→B→C→A допустимы. Направление зависимости определяет тот, кто сослался первым: сослался — значит зависишь, и обратная ссылка из цели запрещена.
- Имена файлов: строчные буквы с дефисами.

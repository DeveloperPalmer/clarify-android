## Requirements

### Данные и методы

Данные экрана платформа получает через методы доступа к данным (раздел `method`). Требования описывают только публичный контракт каждого метода — что платформа **отправляет** и что **получает** в ответ. Что находится за интерфейсом метода (хранилище, бэкенд, кэш) требованиями не рассматривается.

|     | **Requirement**                | **Description**                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                     |
| --- | ------------------------------ | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 1   | Загрузка при открытии          | **Когда:** при открытии экрана.<br>**Платформа подписывается и догружает:**<br>1. [observe-user](../method/user/observe-user.md) — профиль собеседника<br>2. [observe-direct-commits](../method/commit/observe-direct-commits.md) — живой поток сообщений<br>3. [observe-branches](../method/branch/observe-branches.md) — список веток<br>4. [observe-branch-unread-count](../method/unread-count/observe-branch-unread-count.md) — счётчик непрочитанных ветки<br>5. [observe-unread-count](../method/unread-count/observe-unread-count.md) — счётчик непрочитанных треда<br>6. [observe-member](../method/member/observe-member.md) — отметка прочтения собеседника<br>7. [get-commits](../method/commit/get-commits.md) — первая порция истории |
| 2   | Профиль собеседника            | <span style="color:#2563eb">**Метод:**</span> [observe-user](../method/user/observe-user.md) (по `Peer.Id`).<br><span style="color:#0f766e">**Получаем:**</span><br>1. `displayName`<br>2. `email`<br>3. `photoUrl`                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                 |
| 3   | Поток сообщений                | <span style="color:#2563eb">**Метод:**</span> [observe-direct-commits](../method/commit/observe-direct-commits.md).<br><span style="color:#0f766e">**Получаем:**</span> живой поток сообщений основного треда.<br><br>Каждая эмиссия — изменения `added` / `modified` / `removed`.                                                                                                                                                                                                                                                                                                                                                                                                                                                                  |
| 4   | Поля сообщения                 | <span style="color:#0f766e">**Получаем по каждому сообщению:**</span><br>1. `id` — идентификатор<br>2. `senderId` — UID отправителя<br>3. `text` — текст<br>4. `timestamp` — время отправки<br>5. `status` — `sending` / `sent`<br>6. `isSelf` — отправлено текущим пользователем<br>7. признак прочтения собеседником (по его отметке прочтения, см. п. 7)                                                                                                                                                                                                                                                                                                                                                       |
| 5   | Подгрузка истории              | <span style="color:#2563eb">**Метод:**</span> [get-commits](../method/commit/get-commits.md).<br><span style="color:#b45309">**Отправляем:**</span><br>1. `count` — размер порции<br>2. `before` — граница: сообщения раньше указанного<br><span style="color:#0f766e">**Получаем:**</span> порцию более ранних сообщений.<br><br>**Когда:** при прокрутке к началу истории.                                                                                                                                                                                                                                                                                                                                                                        |
| 6   | Отправка сообщения             | <span style="color:#2563eb">**Метод:**</span> [post-commit](../method/commit/post-commit.md).<br><span style="color:#b45309">**Отправляем:**</span><br>1. `text` — текст (обрезанный)<br><span style="color:#15803d">**Результат:**</span> сообщение появляется в конце ленты.<br><br>**Примечание:** беседа создаётся лениво — при первом отправленном сообщении (до этого треда в общем списке переписок ещё нет).                                                                                                                                                                                                                                                                                                        |
| 7   | Отметка прочтения собеседником | <span style="color:#2563eb">**Метод:**</span> [observe-member](../method/member/observe-member.md).<br><span style="color:#0f766e">**Получаем:**</span> момент последнего прочтения собеседником — по нему свои сообщения помечаются прочитанными.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                  |
| 8   | Счётчик непрочитанных          | <span style="color:#2563eb">**Метод:**</span> [observe-unread-count](../method/unread-count/observe-unread-count.md).<br><span style="color:#0f766e">**Получаем:**</span> живой счётчик непрочитанных сообщений треда; `0`, если непрочитанных нет.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                 |
| 9   | Отметка прочтения              | **Когда:** при открытии и при просмотре новых сообщений.<br>**Платформа вызывает:**<br>1. [patch-read-watermark](../method/member/patch-read-watermark.md) — сдвигает отметку прочтения до времени последнего просмотренного сообщения<br>2. [patch-clear-unread-count](../method/unread-count/patch-clear-unread-count.md) — обнуляет счётчик непрочитанных треда                                                                                                                                                                                                                                                                                                                                                                                  |
| 10  | Список веток                   | <span style="color:#2563eb">**Метод:**</span> [observe-branches](../method/branch/observe-branches.md).<br><span style="color:#0f766e">**Получаем:**</span> живой список веток треда.<br>По каждой ветке: `name`, счётчик непрочитанных (см. п. 11) и статус merge request.                                                                                                                                                                                                                                                                                                                                                                                                                                                                         |
| 11  | Непрочитанные по веткам        | <span style="color:#2563eb">**Метод:**</span> [observe-branch-unread-count](../method/unread-count/observe-branch-unread-count.md) (на каждую ветку).<br><span style="color:#0f766e">**Получаем:**</span> живой счётчик непрочитанных ветки, независимый от основного треда.                                                                                                                                                                                                                                                                                                                                                                                                                                                                        |
| 12  | Создание ветки                 | <span style="color:#2563eb">**Метод:**</span> [post-branch](../method/branch/post-branch.md).<br><span style="color:#b45309">**Отправляем:**</span><br>1. `branchedFromCommitId` — сообщение-источник<br>2. `name` — название (обрезанное)<br><span style="color:#0f766e">**Получаем:**</span> созданную ветку.                                                                                                                                                                                                                                                                                                                                                                                                                                     |

### Шапка собеседника

|     | **Requirement**       | **Description**                                                                                                                                                                            |
| --- | --------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 1   | Карточка собеседника  | <span style="color:#0f766e">**Показываем:**</span><br>1. `photoUrl` — аватар<br>2. `displayName` — имя<br><br><span style="color:#2563eb">**Метод:**</span> [observe-user](../method/user/observe-user.md).                                                |
| 2   | Кнопка веток          | **Показываем:** счётчик веток.<br>**Действие:** нажатие открывает список веток (см. «Ветки» → п. 1).                                                                                       |

### Сообщения

|     | **Requirement**         | **Description**                                                                                                                                                                                          |
| --- | ----------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 1   | История                 | **Порядок:** хронологический.<br>**Подгрузка:** более ранние сообщения подгружаются порциями при прокрутке к началу (см. «Данные и методы» → п. 5).                                                       |
| 2   | Отправка                | **Поле:** ввод текста.<br>**Поведение:** по отправке текст обрезается (`trim`); пустое сообщение не отправляется.<br><span style="color:#15803d">**Результат:**</span> сообщение появляется в конце ленты. |
| 3   | Статусы сообщения        | <span style="color:#0f766e">**Показываем:**</span><br>1. `sending` — отправляется<br>2. `sent` — отправлено<br>3. признак прочтения собеседником                                                          |
| 4   | Прокрутка к новым        | **Показываем:** кнопку перехода к последним сообщениям со счётчиком непрочитанных.                                                                                                                        |
| 5   | Пустое состояние        | **Когда:** в треде ещё нет сообщений.<br>**Показываем:** заглушку с приглашением начать переписку.                                                                                                        |

### Непрочитанные

|     | **Requirement**     | **Description**                                                                                                                                                            |
| --- | ------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 1   | Отметка прочтения   | **Когда:** при открытии треда и при просмотре новых сообщений.<br>**Поведение:** платформа сдвигает отметку прочтения и обнуляет счётчик (см. «Данные и методы» → п. 9).    |
| 2   | Независимость веток | Счётчик непрочитанных ведётся отдельно для основного треда и для каждой ветки.                                                                                              |

### Ветки

|     | **Requirement**          | **Description**                                                                                                                                                                                                                                                                                                                                                          |
| --- | ------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 1   | Список веток             | **Действие:** нажатие кнопки веток в шапке.<br>**Показываем:** список веток треда — по каждой `name` и счётчик непрочитанных.                                                                                                                                                                                                                                            |
| 2   | Открытие ветки           | **Действие:** нажатие на ветку в списке.<br><span style="color:#15803d">**Результат:**</span> открывается фича [chat-branch](chat-branch.md) с выбранной веткой.                                                                                                                                                                                                          |
| 3   | Запуск создания          | **Действие:** долгое нажатие на сообщение.<br>**Поведение:** открывается форма создания ветки с полем названия; сообщение становится точкой ответвления.                                                                                                                                                                                                                  |
| 4   | Валидация названия (клиент) | Перед запросом название валидируется на клиенте. Крайние пробелы обрезаются (`trim`). Кнопка создания неактивна при пустом названии. При нескольких нарушениях показывается первое по порядку ниже.<br><br><span style="color:#b91c1c">**Ошибки:**</span><br>1. **пустое** — название пустое после `trim`; сообщение не показывается (кнопка неактивна);<br>2. **слишком длинное** — длина > 40 → «Максимальная длина имени 40»;<br>3. **неверный формат** — не соответствует маске `только латиница, цифры, дефис и подчёркивание` → «Только латиница, цифры, дефис и подчёркивание»;<br>4. **уже существует** — название совпадает с существующей веткой → «Ветка с таким названием уже есть».<br><br>**Сброс ошибки:** при изменении поля и при открытии формы. |
| 5   | Успешное создание        | <span style="color:#2563eb">**Метод:**</span> [post-branch](../method/branch/post-branch.md) (см. «Данные и методы» → п. 12).<br><span style="color:#15803d">**Результат:**</span> ветка появляется в списке и сразу открывается фича [chat-branch](chat-branch.md).                                                                                                       |
| 6   | Ошибка создания          | <span style="color:#b91c1c">**Ошибка:**</span> snackbar «Не удалось создать ветку»; форма закрывается, пользователь остаётся в треде.                                                                                                                                                                                                                                    |

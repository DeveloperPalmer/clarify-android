# Chat-Direct-Thread

**Summary**: Личная переписка 1:1 — история сообщений с подгрузкой, отправка, счётчики непрочитанных, контекстное меню сообщения (создать ветку / редактировать / копировать / выбрать / удалить), редактирование своих сообщений, выбор и удаление сообщений («у себя» и «у всех»), список веток.

**Sources**: `feature/chat-direct-thread` (модули `ui` / `domain` / `data` / `routing`)

## Requirements

### Данные и методы

Данные экрана платформа получает через методы доступа к данным (раздел `method`). Требования описывают только публичный контракт каждого метода — что платформа **отправляет** и что **получает** в ответ. Что находится за интерфейсом метода (хранилище, бэкенд, кэш) требованиями не рассматривается.

|     | **Requirement**                | **Description**                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                     |
| --- | ------------------------------ | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 1   | Загрузка при открытии          | **Когда:** при открытии экрана.<br>**Платформа подписывается и догружает:**<br>1. [user-live](../method/user/user-live.md) — профиль собеседника<br>2. [direct-commits-live](../method/commit/direct-commits-live.md) — живой поток сообщений<br>3. [branches-live](../method/branch/branches-live.md) — список веток<br>4. [branch-unread-count-live](../method/unread-count/branch-unread-count-live.md) — счётчик непрочитанных ветки<br>5. [unread-count-live](../method/unread-count/unread-count-live.md) — счётчик непрочитанных треда<br>6. [member-live](../method/member/member-live.md) — отметка прочтения собеседника<br>7. [read-commits](../method/commit/read-commits.md) — первая порция истории |
| 2   | Профиль собеседника            | <span style="color:#2563eb">**Метод:**</span> [user-live](../method/user/user-live.md) (по `Peer.Id`).<br><span style="color:#0f766e">**Получаем:**</span><br>1. `displayName`<br>2. `email`<br>3. `photoUrl`                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                 |
| 3   | Поток сообщений                | <span style="color:#2563eb">**Метод:**</span> [direct-commits-live](../method/commit/direct-commits-live.md).<br><span style="color:#0f766e">**Получаем:**</span> живой поток сообщений основного треда.<br><br>Каждая эмиссия — изменения `added` / `modified` / `removed`.                                                                                                                                                                                                                                                                                                                                                                                                                                                                  |
| 4   | Поля сообщения                 | <span style="color:#0f766e">**Получаем по каждому сообщению:**</span><br>1. `id` — идентификатор<br>2. `senderId` — UID отправителя<br>3. `text` — текст<br>4. `timestamp` — время отправки<br>5. `status` — `sending` / `sent`<br>6. `isSelf` — отправлено текущим пользователем<br>7. `editedAt` — момент правки; `null`, если сообщение не редактировалось<br>8. признак прочтения собеседником (по его отметке прочтения, см. п. 7)                                                                                                                                                                                                                                                                                                                                                       |
| 5   | Подгрузка истории              | <span style="color:#2563eb">**Метод:**</span> [read-commits](../method/commit/read-commits.md).<br><span style="color:#b45309">**Отправляем:**</span><br>1. `count` — размер порции<br>2. `before` — граница: сообщения раньше указанного<br><span style="color:#0f766e">**Получаем:**</span> порцию более ранних сообщений.<br><br>**Когда:** при прокрутке к началу истории.                                                                                                                                                                                                                                                                                                                                                                        |
| 6   | Отправка сообщения             | <span style="color:#2563eb">**Метод:**</span> [create-direct-commit](../method/commit/create-direct-commit.md).<br><span style="color:#b45309">**Отправляем:**</span><br>1. `text` — текст (обрезанный)<br><span style="color:#15803d">**Результат:**</span> сообщение появляется в конце ленты.<br><br>**Примечание:** беседа создаётся лениво — при первом отправленном сообщении (до этого треда в общем списке переписок ещё нет).                                                                                                                                                                                                                                                                                                        |
| 7   | Отметка прочтения собеседником | <span style="color:#2563eb">**Метод:**</span> [member-live](../method/member/member-live.md).<br><span style="color:#0f766e">**Получаем:**</span> момент последнего прочтения собеседником — по нему свои сообщения помечаются прочитанными.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                  |
| 8   | Счётчик непрочитанных          | <span style="color:#2563eb">**Метод:**</span> [unread-count-live](../method/unread-count/unread-count-live.md).<br><span style="color:#0f766e">**Получаем:**</span> живой счётчик непрочитанных сообщений треда; `0`, если непрочитанных нет.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                 |
| 9   | Отметка прочтения              | **Когда:** при открытии и при просмотре новых сообщений.<br>**Платформа вызывает:**<br>1. [update-read-watermark](../method/member/update-read-watermark.md) — сдвигает отметку прочтения до времени последнего просмотренного сообщения<br>2. [update-unread-count](../method/unread-count/update-unread-count.md) — обнуляет счётчик непрочитанных треда                                                                                                                                                                                                                                                                                                                                                                                  |
| 10  | Список веток                   | <span style="color:#2563eb">**Метод:**</span> [branches-live](../method/branch/branches-live.md).<br><span style="color:#0f766e">**Получаем:**</span> живой список веток треда.<br>По каждой ветке: `name`, счётчик непрочитанных (см. п. 11) и статус merge request.                                                                                                                                                                                                                                                                                                                                                                                                                                                                         |
| 11  | Непрочитанные по веткам        | <span style="color:#2563eb">**Метод:**</span> [branch-unread-count-live](../method/unread-count/branch-unread-count-live.md) (на каждую ветку).<br><span style="color:#0f766e">**Получаем:**</span> живой счётчик непрочитанных ветки, независимый от основного треда.                                                                                                                                                                                                                                                                                                                                                                                                                                                                        |
| 12  | Создание ветки                 | <span style="color:#2563eb">**Метод:**</span> [create-branch](../method/branch/create-branch.md).<br><span style="color:#b45309">**Отправляем:**</span><br>1. `branchedFromCommitId` — сообщение-источник<br>2. `name` — название (обрезанное)<br><span style="color:#0f766e">**Получаем:**</span> созданную ветку.                                                                                                                                                                                                                                                                                                                                                                                                                                                     |
| 13  | Скрытие сообщений «у себя»      | <span style="color:#2563eb">**Метод:**</span> [hide-commits](../method/commit/hide-commits.md).<br><span style="color:#b45309">**Отправляем:**</span><br>1. `commitIds` — выбранные сообщения<br><span style="color:#15803d">**Результат:**</span> сообщения пропадают у текущего пользователя; у собеседника остаются.                                                                                                                                                                                                                                                                                                                                                                                                                                             |
| 14  | Удаление сообщений «у всех»     | <span style="color:#2563eb">**Метод:**</span> [delete-direct-commits](../method/commit/delete-direct-commits.md).<br><span style="color:#b45309">**Отправляем:**</span><br>1. `commitIds` — выбранные сообщения<br>2. `lastCommit` — пересчитанное последнее сообщение беседы: keep / replace / clear<br>3. `peerUnreadDelta` — на сколько уменьшить счётчик непрочитанных собеседника<br><span style="color:#15803d">**Результат:**</span> сообщения удаляются у обоих участников; при необходимости обновляются превью последнего сообщения беседы и счётчик непрочитанных собеседника.                                                                                                                                                                                                                                                                                                                                                                                                                                     |
| 15  | Редактирование сообщения        | <span style="color:#2563eb">**Метод:**</span> [update-direct-commit](../method/commit/update-direct-commit.md).<br><span style="color:#b45309">**Отправляем:**</span><br>1. `commitId` — редактируемое сообщение<br>2. `text` — новый текст (обрезанный)<br><span style="color:#0f766e">**Получаем:**</span> у сообщения появляется `editedAt`.<br><span style="color:#15803d">**Результат:**</span> текст заменён у обоих участников; время отправки не меняется; при правке последнего сообщения беседы обновляется её превью.<br><span style="color:#b91c1c">**Ошибка:**</span> сообщение уже удалено «у всех» — режим сбрасывается (см. «Редактирование» → п. 6). |

|     | **Requirement**       | **Description**                                                                                                                                                                            |

### Сообщения

|     | **Requirement**         | **Description**                                                                                                                                                                                          |
| --- | ----------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 1   | История                 | **Порядок:** хронологический.<br>**Подгрузка:** более ранние сообщения подгружаются порциями при прокрутке к началу (см. «Данные и методы» → п. 5).                                                       |
| 2   | Отправка                | **Поле:** ввод текста.<br>**Поведение:** по отправке текст обрезается (`trim`); пустое сообщение не отправляется.<br><span style="color:#15803d">**Результат:**</span> сообщение появляется в конце ленты. |
| 3   | Статусы сообщения        | <span style="color:#0f766e">**Показываем:**</span><br>1. `sending` — отправляется<br>2. `sent` — отправлено<br>3. признак прочтения собеседником                                                          |
| 4   | Прокрутка к новым        | **Показываем:** кнопку перехода к последним сообщениям со счётчиком непрочитанных.                                                                                                                        |
| 5   | Пустое состояние        | **Когда:** в треде ещё нет сообщений.<br>**Показываем:** заглушку с приглашением начать переписку.                                                                                                        |

### Контекстное меню сообщения

|     | **Requirement**   | **Description**                                                                                                                                                                                                                                                                                    |
| --- | ----------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 1   | Открытие меню     | **Действие:** нажатие на сообщение вне режима выбора.<br>**Поведение:** перед показом скрывается клавиатура; меню приякорено к сообщению со стороны его отправителя (своё — справа, собеседника — слева) и не перекрывает поле ввода; лента затемняется.                                              |
| 2   | Пункты меню       | <span style="color:#0f766e">**Показываем:**</span><br>1. создать ветку<br>2. редактировать — только у своих сообщений<br>3. копировать<br>4. выбрать<br>5. удалить                                                                                                                                 |
| 3   | Создать ветку     | **Действие:** пункт «создать ветку».<br><span style="color:#15803d">**Результат:**</span> меню закрывается, открывается форма создания ветки (см. «Ветки» → пп. 3–5).                                                                                                                                |
| 3.1 | Редактировать     | **Действие:** пункт «редактировать» (виден только у своих сообщений).<br><span style="color:#15803d">**Результат:**</span> меню закрывается, экран переходит в режим редактирования этого сообщения (см. «Редактирование»).                                                                            |
| 4   | Копировать        | **Действие:** пункт «копировать».<br><span style="color:#15803d">**Результат:**</span> текст сообщения копируется в буфер обмена; меню закрывается; показывается snackbar «Скопировано».                                                                                                              |
| 5   | Выбрать           | **Действие:** пункт «выбрать».<br><span style="color:#15803d">**Результат:**</span> меню закрывается, экран переходит в режим выбора с этим сообщением (см. «Выбор и удаление»).                                                                                                                       |
| 6   | Удалить           | **Действие:** пункт «удалить».<br><span style="color:#15803d">**Результат:**</span> меню закрывается, показывается диалог удаления для этого сообщения (см. «Выбор и удаление» → пп. 5–8).                                                                                                            |
| 7   | Закрытие меню     | **Действие:** нажатие по затемнению или системная кнопка «назад».<br><span style="color:#15803d">**Результат:**</span> меню закрывается без изменений.                                                                                                                                                |

### Редактирование

|     | **Requirement**            | **Description**                                                                                                                                                                                                                                                                                                          |
| --- | -------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| 1   | Вход в режим               | **Действие:** пункт «редактировать» контекстного меню (см. «Контекстное меню сообщения» → п. 3.1); доступен только у своих сообщений.<br><span style="color:#0f766e">**Показываем:**</span> шапку над полем ввода — заголовок «Редактировать сообщение», сниппет оригинала (1 строка) и крестик; поле заполняется текстом оригинала; кнопка отправки становится галочкой. Набранный до этого текст перезаписывается, черновики не сохраняются. |
| 2   | Валидация                  | Кнопка отправки неактивна, если текст после `trim` пуст или совпадает с оригиналом. Пустой текст не превращается в удаление. При пустом поле показывается подсказка «Сообщение не может быть пустым».                                                                                                                       |
| 3   | Отправка                   | <span style="color:#2563eb">**Метод:**</span> [update-direct-commit](../method/commit/update-direct-commit.md) (см. «Данные и методы» → п. 15).<br><span style="color:#15803d">**Результат:**</span> текст заменён, рядом со временем появляется метка «изменено»; время отправки и позиция в истории не меняются; режим закрывается, поле очищается.                                                                                             |
| 4   | Отмена                     | **Действие:** крестик в шапке.<br><span style="color:#15803d">**Результат:**</span> режим сбрасывается, поле очищается, сообщение остаётся прежним.                                                                                                                                                                        |
| 5   | Кнопка «назад»             | Режим редактирования не перехватывает системную кнопку «назад»: она закрывает экран, режим исчезает вместе с ним. Режим выбора при этом перехватывает «назад» независимо (см. «Выбор и удаление» → п. 4) — режимы живут параллельно.                                                                                        |
| 6   | Цель удалена               | **Когда:** редактируемое сообщение удалено — локально, собеседником или обнаружено при отправке.<br><span style="color:#15803d">**Результат:**</span> режим сбрасывается, поле очищается, показывается snackbar «Сообщение удалено».                                                                                        |
| 7   | Ошибка отправки            | <span style="color:#b91c1c">**Ошибка:**</span> snackbar «Не удалось изменить сообщение»; режим и набранный текст сохраняются.                                                                                                                                                                                             |
| 8   | Синхронизация              | Правка, выполненная собеседником или на другом устройстве, обновляет текст и метку «изменено» в ленте вживую (см. «Данные и методы» → п. 3, изменения `modified`).                                                                                                                                                          |

### Выбор и удаление

|     | **Requirement**          | **Description**                                                                                                                                                                                                                                                                                                                                          |
| --- | ------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 1   | Вход в режим выбора      | **Действие:** долгое нажатие на сообщение.<br>**Поведение:** экран переходит в режим выбора, сообщение отмечается выбранным.                                                                                                                                                                                                                            |
| 2   | Переключение выбора      | **Действие:** нажатие на сообщение в режиме выбора.<br>**Поведение:** добавляет или снимает отметку выбора. Выбирать можно как свои сообщения, так и сообщения собеседника.                                                                                                                                                                              |
| 3   | Шапка выбора             | <span style="color:#0f766e">**Показываем:**</span><br>1. счётчик выбранных сообщений<br>2. кнопку закрытия режима выбора<br>3. кнопку удаления.                                                                                                                                                                                                          |
| 4   | Выход из режима выбора   | **Действие:** кнопка закрытия в шапке или системная кнопка «назад».<br><span style="color:#15803d">**Результат:**</span> выбор сбрасывается, экран возвращается в обычный режим.                                                                                                                                                                          |
| 5   | Диалог удаления          | **Действие:** кнопка удаления в шапке выбора или пункт «удалить» контекстного меню (см. «Контекстное меню сообщения» → п. 6).<br><span style="color:#0f766e">**Показываем:**</span> диалог подтверждения с числом удаляемых сообщений и переключателем «Удалить у <имя собеседника>» (включён по умолчанию).                                              |
| 6   | Удаление у всех          | **Когда:** переключатель «удалить у собеседника» включён.<br><span style="color:#2563eb">**Метод:**</span> [delete-direct-commits](../method/commit/delete-direct-commits.md) (см. «Данные и методы» → п. 14).<br><span style="color:#15803d">**Результат:**</span> сообщения удаляются у обоих участников, выбор сбрасывается.                              |
| 7   | Удаление у себя          | **Когда:** переключатель «удалить у собеседника» выключен.<br><span style="color:#2563eb">**Метод:**</span> [hide-commits](../method/commit/hide-commits.md) (см. «Данные и методы» → п. 13).<br><span style="color:#15803d">**Результат:**</span> сообщения пропадают только у текущего пользователя, у собеседника остаются; выбор сбрасывается.          |
| 8   | Ошибка удаления          | <span style="color:#b91c1c">**Ошибка:**</span> snackbar «Не удалось удалить»; режим выбора остаётся активным.                                                                                                                                                                                                                                           |

### Непрочитанные

|     | **Requirement**     | **Description**                                                                                                                                                            |
| --- | ------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |

### Ветки

|     | **Requirement**          | **Description**                                                                                                                                                                                                                                                                                                                                                          |
| --- | ------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 1   | Список веток             | **Действие:** нажатие кнопки веток в шапке.<br>**Показываем:** список веток треда — по каждой `name` и счётчик непрочитанных.                                                                                                                                                                                                                                            |
| 2   | Открытие ветки           | **Действие:** нажатие на ветку в списке.<br><span style="color:#15803d">**Результат:**</span> открывается фича [chat-branch](chat-branch.md) с выбранной веткой.                                                                                                                                                                                                          |
| 3   | Запуск создания          | **Действие:** пункт «создать ветку» в контекстном меню сообщения (см. «Контекстное меню сообщения» → п. 3).<br>**Поведение:** открывается форма создания ветки для выбранного сообщения-источника. Валидация названия и метод создания описаны в пп. 4–5 ниже. |
| 4   | Валидация названия (клиент) | Перед запросом название валидируется на клиенте. Крайние пробелы обрезаются (`trim`). Кнопка создания неактивна при пустом названии. При нескольких нарушениях показывается первое по порядку ниже.<br><br><span style="color:#b91c1c">**Ошибки:**</span><br>1. **пустое** — название пустое после `trim`; сообщение не показывается (кнопка неактивна);<br>2. **слишком длинное** — длина > 40 → «Максимальная длина имени 40»;<br>3. **неверный формат** — не соответствует маске `только латиница, цифры, дефис и подчёркивание` → «Только латиница, цифры, дефис и подчёркивание»;<br>4. **уже существует** — название совпадает с существующей веткой → «Ветка с таким названием уже есть».<br><br>**Сброс ошибки:** при изменении поля и при открытии формы. |
| 5   | Успешное создание        | <span style="color:#2563eb">**Метод:**</span> [create-branch](../method/branch/create-branch.md) (см. «Данные и методы» → п. 12).<br><span style="color:#15803d">**Результат:**</span> ветка появляется в списке и сразу открывается фича [chat-branch](chat-branch.md).                                                                                                       |
| 6   | Ошибка создания          | <span style="color:#b91c1c">**Ошибка:**</span> snackbar «Не удалось создать ветку»; форма закрывается, пользователь остаётся в треде.                                                                                                                                                                                                                                    |

## Requirements

### Данные и методы

Выход из аккаунта выполняется через внутренние операции приложения — выход у провайдера входа (Google) и сброс сессии. Это не методы доступа к данным, поэтому они упоминаются inline-кодом без отдельных страниц.

|     | **Requirement**   | **Description**                                                                                                                                                                                                                                                                                                                                                                                                                                                                                |
| --- | ----------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 1   | Выход из аккаунта | **Когда:** по подтверждению выхода.<br>**Платформа выполняет по порядку:**<br>1. <span style="color:#2563eb">**Метод:**</span> выход у провайдера (`sign-out`) — завершает сессию Google.<br>2. <span style="color:#2563eb">**Метод:**</span> сброс сессии (`reset-session`) — сбрасывает локальную сессию с очисткой сохранённых данных.<br><br><span style="color:#b45309">**Отправляем:**</span> ничего.<br><span style="color:#15803d">**Результат:**</span> сессия становится `inactive`. |

### Экран профиля

|     | **Requirement**            | **Description**                                                                                                                                                                                                       |
| --- | -------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 1   | Состав экрана              | **Показываем:** единственное действие — кнопка **«Выйти»**.<br><br>**Статус:** отображение данных профиля (аватар, имя, email) на этом экране не реализовано — карточка пользователя живёт в шапке главного экрана. |
| 2   | Назад с экрана профиля     | **Действие:** «назад».<br><span style="color:#15803d">**Результат:**</span> экран профиля закрывается без выхода из аккаунта; платформа возвращается на предыдущий экран.                                              |

### Выход из аккаунта

|     | **Requirement**             | **Description**                                                                                                                                                                                                                                  |
| --- | --------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 1   | Запуск выхода               | **Действие:** нажатие кнопки «Выйти».<br><span style="color:#2563eb">**Метод:**</span> выход из аккаунта (см. «Данные и методы» → п. 1).                                                                                                          |
| 2   | Защита от повторного нажатия | **Когда:** выход уже выполняется.<br>**Поведение:**<br>1. на время выхода показывается индикатор выполнения;<br>2. повторное нажатие не запускает второй выход.                                                                                  |
| 3   | Успешный выход              | <span style="color:#15803d">**Результат:**</span> по порядку:<br>1. сессия завершается и становится `inactive`;<br>2. экран профиля закрывается;<br>3. приложение возвращается на экран входа — фича [authorization](authorization.md).           |

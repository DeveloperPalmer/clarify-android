# Chat-Conversation

**Summary**: Главный экран приложения — список всех активных переписок пользователя, точка создания новых чатов и навигации в них. Групповые чаты закрыты за признаком доступности (по умолчанию выключены) — по умолчанию экран работает в режиме «только личные чаты».

## Requirements

### Доступность групповых чатов

Групповая функциональность управляется бизнес-признаком доступности («доступность групп», feature toggle). Признак определяет, доступны ли группы на главном экране и в соседних фичах.

|    | **Requirement**              | **Description**                                                                                                                                                                                                                                                                                                                       |
|----|------------------------------|--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|  1 | Признак доступности групп    | Групповые чаты доступны только при включённом признаке «доступность групп».<br>**По умолчанию:** признак **выключен**.<br>**Причина:** групповая функциональность сырая и пока не соответствует бизнес-ожиданиям; закрыта сознательно, включается адресно и будет дорабатываться позже.                                                    |
|  2 | Режим «только личные чаты»    | **Когда:** признак выключен (поведение по умолчанию).<br>**Поведение:**<br>1. групповые беседы не показываются в списке переписок;<br>2. диалог создания чата содержит только вкладку личного чата (вкладки «группа» нет);<br>3. открытие и создание групп недоступны.<br><br>Личные переписки при этом работают в полном объёме.          |
|  3 | Режим с группами             | **Когда:** признак включён.<br>**Поведение:** экран работает в полном объёме, как описано в остальных разделах: группы в общем списке, вкладка «группа» в диалоге создания, открытие групповых тредов.                                                                                                                                    |

### Данные и методы

Данные экрана платформа получает через методы доступа к данным (раздел `method`). Требования описывают только публичный контракт каждого метода — что платформа **отправляет** и что **получает** в ответ. Что находится за интерфейсом метода (хранилище, бэкенд, кэш) требованиями не рассматривается.

|    | **Requirement**        | **Description**                                                                                                                                                                                                                                                                                                       |
|----|------------------------|--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|  1 | Загрузка при открытии  | **Когда:** при открытии экрана.<br>**Платформа вызывает:**<br>1. [conversations-live](../method/conversation/conversations-live.md) — подписка на беседы<br>2. [unread-count-live](../method/unread-count/unread-count-live.md) — подписка на счётчики непрочитанных (на каждую беседу)<br>3. [read-user](../method/user/read-user.md) — профили участников<br>4. [read-current-user](../method/user/read-current-user.md) — текущий пользователь                                |
|  2 | Подписка на беседы     | <span style="color:#2563eb">**Метод:**</span> [conversations-live](../method/conversation/conversations-live.md).<br><span style="color:#0f766e">**Получаем:**</span> живой поток всех бесед текущего пользователя.<br>* direct<br>* group (тип в поле `type`)<br><br>Каждая эмиссия — изменения `added` / `modified` / `removed`.                               |
|  3 | Поля беседы            | <span style="color:#0f766e">**Получаем по каждой беседе:**</span><br>1. `id` — идентификатор беседы<br>2. `type` — тип беседы (`direct` / `group`)<br>3. `memberUids` — список UID участников<br>4. `name` — название группы (только group)<br>5. `ownerUid` — UID владельца группы (только group)<br>6. `lastCommitText` — текст последнего сообщения<br>7. `lastCommitSenderUid` — UID отправителя последнего сообщения<br>8. `lastCommitAt` — время последнего сообщения<br><br>**Удаление:** изменение `removed` — беседа исчезает из списка. |
|  4 | Профили участников     | <span style="color:#2563eb">**Метод:**</span> [read-user](../method/user/read-user.md) (по `UserId`).<br><span style="color:#0f766e">**Получаем:**</span><br>1. `displayName`<br>2. `email`<br>3. `photoUrl`<br><br>**Зачем:** [conversations-live](../method/conversation/conversations-live.md) отдаёт только UID-ы; имя и аватар собеседника (direct) и отправителя последнего сообщения (group) платформа догружает отдельно. |
|  5 | Счётчики непрочитанных | <span style="color:#2563eb">**Метод:**</span> [unread-count-live](../method/unread-count/unread-count-live.md) (на каждую беседу).<br><span style="color:#0f766e">**Получаем:**</span> живой счётчик непрочитанных сообщений беседы; `0`, если непрочитанных нет.                                                                                              |
|  6 | Текущий пользователь   | <span style="color:#2563eb">**Метод:**</span> [read-current-user](../method/user/read-current-user.md).<br><span style="color:#0f766e">**Получаем:**</span><br>1. `displayName`<br>2. `email`<br>3. `photoUrl`<br><br>**Для:** шапки экрана.                                                                                                                                              |
|  7 | Сборка списка          | **Состав:** direct + group в одном списке.<br>**Сортировка:** по `lastCommitAt`, убывание (новейшие сверху).<br><br>**Доступность групп:** групповые беседы попадают в список только при включённом признаке доступности групп (см. «Доступность групповых чатов»); при выключенном список содержит только личные переписки. Метод [conversations-live](../method/conversation/conversations-live.md) при этом возвращает и direct, и group — отбор групп происходит на стороне платформы. |

### Список и превью переписок

|    | **Requirement**  | **Description**                                                                                                                                                                                                            |
|----|------------------|------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|  1 | Список переписок | **Состав:** личные и групповые в одном списке.<br>**Порядок:** см. «Данные и методы» → п. 7.<br><br>**Доступность:** групповые переписки в списке — только при включённом признаке доступности групп (см. «Доступность групповых чатов»); по умолчанию список только личный.                                                                                                                              |
|  2 | Превью личной    | <span style="color:#0f766e">**Показываем:**</span><br>1. `memberUids` — по второму UID берём профиль собеседника (аватар, имя)<br>2. `lastCommitText` — последнее сообщение<br>3. `lastCommitAt` — время<br>4. счётчик непрочитанных |
|  3 | Превью групповой | <span style="color:#0f766e">**Показываем:**</span><br>1. `name` — название<br>2. `lastCommitText` — последнее сообщение<br>3. `lastCommitSenderUid` — имя отправителя (берём профиль по этому UID)<br>4. `lastCommitAt` — время<br>5. счётчик непрочитанных |
|  4 | Пустое состояние | **Когда:** нет ни одной переписки.<br>**Показываем:** заглушку с иллюстрацией и пояснительным текстом.                                                                                                                     |

### Открытие переписки

|    | **Requirement**             | **Description**                                                                                                                  |
|----|-----------------------------|--------------------------------------------------------------------------------------------------------------------------------|
|  1 | Открыть личную переписку    | **Действие:** нажатие на direct-элемент.<br><span style="color:#15803d">**Результат:**</span> фича [chat-direct-thread](chat-direct-thread.md) с `Peer.Id` собеседника. |
|  2 | Открыть групповую переписку | **Действие:** нажатие на group-элемент.<br><span style="color:#15803d">**Результат:**</span> фича [chat-group-thread](chat-group-thread.md) с `Conversation.Id`.<br><br>**Доступность:** только при включённом признаке доступности групп (см. «Доступность групповых чатов»); при выключенном групп в списке нет и переход не происходит. |

### Создание чата

|    | **Requirement**      | **Description**                                                                                                                                                  |
|----|----------------------|----------------------------------------------------------------------------------------------------------------------------------------------------------------|
|  1 | Точка входа          | **Действие:** кнопка FAB.<br><span style="color:#15803d">**Результат:**</span> диалог создания чата.<br>**Состав диалога зависит от признака доступности групп** (см. «Доступность групповых чатов»):<br>1. признак включён — две вкладки: **личный чат** (по email) и **группа** (по названию);<br>2. признак выключен (по умолчанию) — только создание **личного чата**, вкладок нет. |
|  2 | Переключение вкладок | **Доступность:** только когда признак доступности групп включён (иначе вкладок нет).<br>**Действие:** переключение вкладки.<br>**Поведение:** содержимое меняется; уже введённые значения сохраняются. Ошибка валидации активной вкладки сбрасывается.    |
|  3 | Защита от повторной отправки | **Когда:** запрос (поиск собеседника / создание группы) уже выполняется.<br>**Поведение:**<br>1. кнопка подтверждения неактивна, пока запрос в процессе;<br>2. повторное подтверждение не запускает второй запрос — дубликат беседы/группы не создаётся. |

### Начало личной переписки (direct)

|    | **Requirement**   | **Description**                                                                                                                                                                                                                          |
|----|-------------------|----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|  1 | Ввод email        | **Поле:** email.<br>**Кнопка:** активна при непустом поле и неактивна, пока выполняется поиск.<br>**Когда валидируется:** по нажатию кнопки подтверждения (не на лету).<br>**Сброс ошибки:** при изменении поля и при переключении вкладки. |
|  2 | Валидация email (клиент) | Перед запросом адрес валидируется на клиенте. Крайние пробелы обрезаются (`trim`), проверки идут по обрезанному значению. При нескольких нарушениях показывается первое по порядку ниже.<br><br><span style="color:#b91c1c">**Ошибки:**</span><br>1. **пустое** — поле пустое после `trim`; сообщение не показывается (кнопка неактивна);<br>2. **слишком короткий** — длина < 5 → «Email слишком короткий (минимум 5 символов).»;<br>3. **слишком длинный** — длина > 100 → «Email слишком длинный (максимум 100 символов).»;<br>4. **диалог с собой** — адрес совпадает с email текущего пользователя (без учёта регистра и крайних пробелов) → «Нельзя начать диалог с самим собой.»;<br>5. **неверный формат** — не соответствует маске `текст@текст.текст` → «Неверный формат email. Пример: name@example.com».<br><br>**Поведение при ошибке:** запрос не отправляется, диалог остаётся открытым, под полем показывается сообщение. |
|  3 | Поиск собеседника | <span style="color:#2563eb">**Метод:**</span> [read-user-id-by-email](../method/user/read-user-id-by-email.md).<br><span style="color:#b45309">**Отправляем:**</span> email (обрезанный).<br><span style="color:#0f766e">**Получаем:**</span> `UserId` собеседника либо «не найден».              |
|  4 | Успешный поиск    | <span style="color:#15803d">**Результат:**</span> `UserId` → `Peer.Id`, диалог закрывается, открывается фича [chat-direct-thread](chat-direct-thread.md).<br><br>**Примечание:** беседа создаётся не сразу — при первом отправленном сообщении (см. [chat-direct-thread](chat-direct-thread.md)).      |
|  5 | Ошибки поиска     | <span style="color:#b91c1c">**Ошибка (не найден):**</span> пользователя с таким email нет → сообщение «пользователь не найден».<br><span style="color:#b91c1c">**Ошибка (прочее):**</span> сбой запроса → «не удалось выполнить поиск».<br><br>**Поведение:** диалог остаётся открытым. |

### Создание группы (group)

|    | **Requirement**     | **Description**                                                                                                                                                                                                  |
|----|---------------------|------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|  1 | Ввод названия       | **Поле:** название группы.<br>**Кнопка:** активна при непустом названии (после `trim`) и неактивна, пока выполняется создание.<br>**Когда валидируется:** по нажатию кнопки подтверждения (не на лету).<br>**Сброс ошибки:** при изменении поля и при переключении вкладки. |
|  2 | Валидация названия (клиент) | Перед запросом название валидируется на клиенте. Крайние пробелы обрезаются (`trim`), проверки идут по обрезанному значению.<br><br><span style="color:#b91c1c">**Ошибки:**</span><br>1. **пустое** — название пустое после `trim`; сообщение не показывается (кнопка неактивна);<br>2. **слишком длинное** — длина > 50 → «Название не длиннее 50 символов.».<br><br>**Поведение при ошибке:** запрос не отправляется, диалог остаётся открытым, под полем показывается сообщение. |
|  3 | Создание группы     | <span style="color:#2563eb">**Метод:**</span> [create-group-conversation](../method/conversation/create-group-conversation.md).<br><span style="color:#b45309">**Отправляем:**</span> `{ name }` (обрезанное).<br><span style="color:#0f766e">**Получаем:**</span> `conversationId` созданной группы. |
|  4 | Немедленный переход | <span style="color:#15803d">**Результат:**</span> группа сразу появляется в списке и открывается фича [chat-group-thread](chat-group-thread.md).<br><br>**Зачем:** чтобы тред не открылся пустым.                                               |
|  5 | Ошибка создания     | <span style="color:#b91c1c">**Ошибка:**</span> snackbar об ошибке создания, пользователь остаётся на списке.                                                                                                       |

### Режим выделения и удаление

|    | **Requirement**    | **Description**                                                                                                                                                                                                                |
|----|--------------------|----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|  1 | Вход в режим       | **Действие:** долгое нажатие на переписку.<br><span style="color:#15803d">**Результат:**</span> включается режим выделения, переписка добавлена в выделение.                                                                   |
|  2 | Мультивыбор        | **Действие:** нажатие на переписку в режиме выделения.<br>**Поведение:** добавляет/убирает её из выделения; можно выбрать несколько.<br><br>**Авто-выход:** когда выделение пустеет, режим выключается.                        |
|  3 | Удаление переписок | **Действие:** удаление выбранных → подтверждающий диалог.<br><span style="color:#2563eb">**Метод:**</span> [delete-conversations](../method/conversation/delete-conversations.md).<br><span style="color:#b45309">**Отправляем:**</span> `{ ids: [...] }`.<br><span style="color:#15803d">**Результат:**</span> беседы исчезают из списка; режим выделения выключается. |
|  4 | Выход из режима    | **В режиме:** «назад» выходит из режима без удаления.<br>**Вне режима:** «назад» закрывает экран (возврат из флоу).                                                                                                             |

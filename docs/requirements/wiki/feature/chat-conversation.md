## Requirements

### Данные и методы

Данные экрана платформа получает через методы доступа к данным (раздел `method`). Требования описывают только публичный контракт каждого метода — что платформа **отправляет** и что **получает** в ответ. Что находится за интерфейсом метода (хранилище, бэкенд, кэш) требованиями не рассматривается.

|    | **Requirement**        | **Description**                                                                                                                                                                                                                                                                                                       |
|----|------------------------|--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|  1 | Загрузка при открытии  | **Когда:** при открытии экрана.<br>**Платформа вызывает:**<br>1. [observe-conversations](../method/conversation/observe-conversations.md) — подписка на беседы<br>2. [observe-unread-count](../method/unread-count/observe-unread-count.md) — подписка на счётчики непрочитанных (на каждую беседу)<br>3. [get-user](../method/user/get-user.md) — профили участников<br>4. [get-current-user](../method/user/get-current-user.md) — текущий пользователь                                |
|  2 | Подписка на беседы     | <span style="color:#2563eb">**Метод:**</span> [observe-conversations](../method/conversation/observe-conversations.md).<br><span style="color:#0f766e">**Получаем:**</span> живой поток всех бесед текущего пользователя.<br>1. direct<br>2. group (тип в поле `type`)<br><br>Каждая эмиссия — изменения `added` / `modified` / `removed`.                               |
|  3 | Поля беседы            | <span style="color:#0f766e">**Получаем по каждой беседе:**</span><br>1. `id` — идентификатор беседы<br>2. `type` — тип беседы (`direct` / `group`)<br>3. `memberUids` — список UID участников<br>4. `name` — название группы (только group)<br>5. `ownerUid` — UID владельца группы (только group)<br>6. `lastCommitText` — текст последнего сообщения<br>7. `lastCommitSenderUid` — UID отправителя последнего сообщения<br>8. `lastCommitAt` — время последнего сообщения<br><br>**Удаление:** изменение `removed` — беседа исчезает из списка. |
|  4 | Профили участников     | <span style="color:#2563eb">**Метод:**</span> [get-user](../method/user/get-user.md) (по `UserId`).<br><span style="color:#0f766e">**Получаем:**</span><br>1. `displayName`<br>2. `email`<br>3. `photoUrl`<br><br>**Зачем:** [observe-conversations](../method/conversation/observe-conversations.md) отдаёт только UID-ы; имя и аватар собеседника (direct) и отправителя последнего сообщения (group) платформа догружает отдельно. |
|  5 | Счётчики непрочитанных | <span style="color:#2563eb">**Метод:**</span> [observe-unread-count](../method/unread-count/observe-unread-count.md) (на каждую беседу).<br><span style="color:#0f766e">**Получаем:**</span> живой счётчик непрочитанных сообщений беседы; `0`, если непрочитанных нет.                                                                                              |
|  6 | Текущий пользователь   | <span style="color:#2563eb">**Метод:**</span> [get-current-user](../method/user/get-current-user.md).<br><span style="color:#0f766e">**Получаем:**</span><br>1. `displayName`<br>2. `email`<br>3. `photoUrl`<br><br>**Для:** шапки экрана.                                                                                                                                              |
|  7 | Сборка списка          | **Состав:** direct + group в одном списке.<br>**Сортировка:** по `lastCommitAt`, убывание (новейшие сверху).                                                                                                                                                                                                          |

### Список и превью переписок

|    | **Requirement**  | **Description**                                                                                                                                                                                                            |
|----|------------------|------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|  1 | Список переписок | **Состав:** личные и групповые в одном списке.<br>**Порядок:** см. «Данные и методы» → п. 7.                                                                                                                              |
|  2 | Превью личной    | <span style="color:#0f766e">**Показываем:**</span><br>1. `memberUids` — по второму UID берём профиль собеседника (аватар, имя)<br>2. `lastCommitText` — последнее сообщение<br>3. `lastCommitAt` — время<br>4. счётчик непрочитанных |
|  3 | Превью групповой | <span style="color:#0f766e">**Показываем:**</span><br>1. `name` — название<br>2. `lastCommitText` — последнее сообщение<br>3. `lastCommitSenderUid` — имя отправителя (берём профиль по этому UID)<br>4. `lastCommitAt` — время<br>5. счётчик непрочитанных |
|  4 | Пустое состояние | **Когда:** нет ни одной переписки.<br>**Показываем:** заглушку с иллюстрацией и пояснительным текстом.                                                                                                                     |

### Шапка пользователя

|    | **Requirement**       | **Description**                                                                                                                              |
|----|-----------------------|--------------------------------------------------------------------------------------------------------------------------------------------|
|  1 | Карточка пользователя | <span style="color:#0f766e">**Показываем:**</span><br>1. `photoUrl` — аватар<br>2. `displayName` — имя<br>3. `email` — email<br><br><span style="color:#2563eb">**Метод:**</span> [get-current-user](../method/user/get-current-user.md). |
|  2 | Переход в профиль     | **Действие:** нажатие на карточку.<br><span style="color:#15803d">**Результат:**</span> открывается фича [profile](profile.md).                          |

### Открытие переписки

|    | **Requirement**             | **Description**                                                                                                                  |
|----|-----------------------------|--------------------------------------------------------------------------------------------------------------------------------|
|  1 | Открыть личную переписку    | **Действие:** нажатие на direct-элемент.<br><span style="color:#15803d">**Результат:**</span> фича [chat-direct-thread](chat-direct-thread.md) с `Peer.Id` собеседника. |
|  2 | Открыть групповую переписку | **Действие:** нажатие на group-элемент.<br><span style="color:#15803d">**Результат:**</span> фича [chat-group-thread](chat-group-thread.md) с `Conversation.Id`.       |

### Создание чата

|    | **Requirement**      | **Description**                                                                                                                                                  |
|----|----------------------|----------------------------------------------------------------------------------------------------------------------------------------------------------------|
|  1 | Точка входа          | **Действие:** кнопка FAB.<br><span style="color:#15803d">**Результат:**</span> диалог с двумя вкладками:<br>1. **личный чат** (по email)<br>2. **группа** (по названию) |
|  2 | Переключение вкладок | **Действие:** переключение вкладки.<br>**Поведение:** содержимое меняется; уже введённые значения сохраняются.                                                  |

### Начало личной переписки (direct)

|    | **Requirement**   | **Description**                                                                                                                                                                                                                          |
|----|-------------------|----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|  1 | Ввод email        | **Поле:** email.<br>**Кнопка:** активна при непустом поле.<br>**Валидация:** формат адреса проверяется на клиенте перед запросом.                                                                                                       |
|  2 | Поиск собеседника | <span style="color:#2563eb">**Метод:**</span> [get-user-id-by-email](../method/user/get-user-id-by-email.md).<br><span style="color:#b45309">**Отправляем:**</span> email.<br><span style="color:#0f766e">**Получаем:**</span> `UserId` собеседника либо «не найден».              |
|  3 | Успешный поиск    | <span style="color:#15803d">**Результат:**</span> `UserId` → `Peer.Id`, диалог закрывается, открывается фича [chat-direct-thread](chat-direct-thread.md).<br><br>**Примечание:** беседа создаётся не сразу — при первом отправленном сообщении (см. [chat-direct-thread](chat-direct-thread.md)).      |
|  4 | Ошибки поиска     | <span style="color:#b91c1c">**Ошибка (не найден):**</span> пользователя с таким email нет → сообщение «пользователь не найден».<br><span style="color:#b91c1c">**Ошибка (прочее):**</span> сбой запроса → «не удалось выполнить поиск».<br><br>**Поведение:** диалог остаётся открытым. |

### Создание группы (group)

|    | **Requirement**     | **Description**                                                                                                                                                                                                  |
|----|---------------------|------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|  1 | Ввод названия       | **Поле:** название группы.<br>**Кнопка:** активна при непустом названии (после `trim`).                                                                                                                           |
|  2 | Создание группы     | <span style="color:#2563eb">**Метод:**</span> [post-group-conversation](../method/conversation/post-group-conversation.md).<br><span style="color:#b45309">**Отправляем:**</span> `{ name }`.<br><span style="color:#0f766e">**Получаем:**</span> `conversationId` созданной группы. |
|  3 | Немедленный переход | <span style="color:#15803d">**Результат:**</span> группа сразу появляется в списке и открывается фича [chat-group-thread](chat-group-thread.md).<br><br>**Зачем:** чтобы тред не открылся пустым.                                               |
|  4 | Ошибка создания     | <span style="color:#b91c1c">**Ошибка:**</span> snackbar об ошибке создания, пользователь остаётся на списке.                                                                                                       |

### Режим выделения и удаление

|    | **Requirement**    | **Description**                                                                                                                                                                                                                |
|----|--------------------|----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|  1 | Вход в режим       | **Действие:** долгое нажатие на переписку.<br><span style="color:#15803d">**Результат:**</span> включается режим выделения, переписка добавлена в выделение.                                                                   |
|  2 | Мультивыбор        | **Действие:** нажатие на переписку в режиме выделения.<br>**Поведение:** добавляет/убирает её из выделения; можно выбрать несколько.<br><br>**Авто-выход:** когда выделение пустеет, режим выключается.                        |
|  3 | Удаление переписок | **Действие:** удаление выбранных → подтверждающий диалог.<br><span style="color:#2563eb">**Метод:**</span> [delete-conversations](../method/conversation/delete-conversations.md).<br><span style="color:#b45309">**Отправляем:**</span> `{ ids: [...] }`.<br><span style="color:#15803d">**Результат:**</span> беседы исчезают из списка; режим выделения выключается. |
|  4 | Выход из режима    | **В режиме:** «назад» выходит из режима без удаления.<br>**Вне режима:** «назад» закрывает экран (возврат из флоу).                                                                                                             |

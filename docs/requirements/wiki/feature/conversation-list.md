## Requirements

|    | **Requirement**              | **Description**                                                                                                                                          |
|----|------------------------------|----------------------------------------------------------------------------------------------------------------------------------------------------------|
|  1 | Список переписок             | Экран отображает все переписки пользователя — личные и групповые — в одном списке, отсортированном по времени последнего сообщения (новейшие сверху).    |
|  2 | Превью переписки             | Для каждой переписки отображаются: последнее сообщение, время его отправки, счётчик непрочитанных сообщений.                                             |
|  3 | Открыть личную переписку     | По нажатию на личную переписку открывается `direct-chat`.                                                                                                |
|  4 | Открыть групповую переписку  | По нажатию на групповую переписку открывается `group-chat`.                                                                                              |
|  5 | Создать группу               | Пользователь вводит название группы. После создания группа появляется в списке.                                                                          |
|  6 | Начать личную переписку      | Пользователь находит собеседника по email-адресу. После выбора открывается `direct-chat`.                                                                |
|  7 | Удалить переписку            | Переписка удаляется из списка.                                                                                                                           |

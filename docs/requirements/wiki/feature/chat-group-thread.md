## Requirements

|    | **Requirement**         | **Description**                                                                                                                                                              |
|----|-------------------------|------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|  1 | Создание группы         | Группа создаётся из `chat-conversation`. Пользователь задаёт название. Создатель становится владельцем.                                                                     |
|  2 | Роли участников         | В группе две роли: **Владелец** (создатель) и **Участник** (все остальные). Роль определяет доступные действия.                                                              |
|  3 | Действия владельца      | Владелец может: переименовать группу, удалить группу, удалить любого участника.                                                                                              |
|  4 | Действия участника      | Любой участник может: отправлять сообщения, приглашать других пользователей, покинуть группу.                                                                                |
|  5 | Приглашение участников  | Поиск пользователя по email-адресу. После выбора пользователь добавляется в группу.                                                                                          |
|  6 | Экран информации о группе | Отдельный экран с названием группы, количеством участников и их списком. Отсюда доступны действия по управлению (п. 3–4).                                                   |
|  7 | Отсутствие веток        | В групповом чате нет `chat-branch`. Это плоская переписка.                                                                                                                   |

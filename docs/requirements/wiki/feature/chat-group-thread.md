## Requirements

### Данные и методы

Данные экрана платформа получает через методы доступа к данным (раздел `method`). Требования описывают только публичный контракт каждого метода — что платформа **отправляет** и что **получает** в ответ. Что находится за интерфейсом метода (хранилище, бэкенд, кэш) требованиями не рассматривается.

Данные самой группы (название, владелец, число участников) платформа уже имеет из общего потока бесед главного экрана; здесь дополнительно подписывается на сообщения и участников этой группы.

|     | **Requirement**          | **Description**                                                                                                                                                                                                                                                                                                                                                                                                                                                                                |
| --- | ------------------------ | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 1   | Загрузка при открытии    | **Когда:** при открытии экрана.<br>**Платформа подписывается и догружает:**<br>1. [observe-group-commits](../method/commit/observe-group-commits.md) — живой поток сообщений<br>2. [observe-members](../method/member/observe-members.md) — участники группы<br>3. [observe-unread-count](../method/unread-count/observe-unread-count.md) — счётчик непрочитанных<br>4. [get-commits](../method/commit/get-commits.md) — первая порция истории |
| 2   | Поток сообщений          | <span style="color:#2563eb">**Метод:**</span> [observe-group-commits](../method/commit/observe-group-commits.md).<br><span style="color:#0f766e">**Получаем:**</span> живой поток сообщений группы.<br><br>Каждая эмиссия — изменения `added` / `modified` / `removed`.                                                                                                                                                                                                                          |
| 3   | Поля сообщения           | <span style="color:#0f766e">**Получаем по каждому сообщению:**</span><br>1. `id` — идентификатор<br>2. `senderId` — UID отправителя<br>3. `text` — текст<br>4. `timestamp` — время отправки<br>5. `status` — `sending` / `sent`<br>6. `isSelf` — отправлено текущим пользователем<br><br>**Зачем:** имя и аватар отправителя подставляются из списка участников (см. п. 6).                                                                                                |
| 4   | Подгрузка истории        | <span style="color:#2563eb">**Метод:**</span> [get-commits](../method/commit/get-commits.md).<br><span style="color:#b45309">**Отправляем:**</span><br>1. `count` — размер порции<br>2. `before` — граница: сообщения раньше указанного<br><span style="color:#0f766e">**Получаем:**</span> порцию более ранних сообщений.                                                                                                                                                                       |
| 5   | Отправка сообщения       | <span style="color:#2563eb">**Метод:**</span> [post-group-commit](../method/commit/post-group-commit.md).<br><span style="color:#b45309">**Отправляем:**</span> `text` — текст (обрезанный).<br><span style="color:#15803d">**Результат:**</span> сообщение появляется в конце ленты.                                                                                                                                                                                                            |
| 6   | Участники группы         | <span style="color:#2563eb">**Метод:**</span> [observe-members](../method/member/observe-members.md).<br><span style="color:#0f766e">**Получаем по каждому участнику:**</span><br>1. `displayName`<br>2. `email`<br>3. `photoUrl`<br>4. `isOwner` — является ли владельцем группы<br>5. `isMe` — текущий пользователь                                                                                                                                                                             |
| 7   | Счётчик непрочитанных    | <span style="color:#2563eb">**Метод:**</span> [observe-unread-count](../method/unread-count/observe-unread-count.md).<br><span style="color:#0f766e">**Получаем:**</span> живой счётчик непрочитанных сообщений группы; `0`, если непрочитанных нет.                                                                                                                                                                                                                                             |
| 8   | Отметка прочтения        | **Когда:** при появлении новых сообщений в открытом треде.<br>**Платформа вызывает:**<br>1. [patch-read-watermark](../method/member/patch-read-watermark.md) — сдвигает отметку прочтения до времени самого нового сообщения<br>2. [patch-clear-unread-count](../method/unread-count/patch-clear-unread-count.md) — обнуляет счётчик непрочитанных                                                                                                                                                |
| 9   | Поиск кандидатов         | <span style="color:#2563eb">**Метод:**</span> [get-users-by-email-prefix](../method/user/get-users-by-email-prefix.md).<br><span style="color:#b45309">**Отправляем:**</span> префикс email (в нижнем регистре).<br><span style="color:#0f766e">**Получаем:**</span> список пользователей, чей email начинается с префикса.                                                                                                                                                                      |
| 10  | Приглашение участника    | <span style="color:#2563eb">**Метод:**</span> [post-invite-member](../method/member/post-invite-member.md) (по каждому выбранному).<br><span style="color:#b45309">**Отправляем:**</span> `userId` приглашаемого.<br><span style="color:#15803d">**Результат:**</span> пользователь добавляется в группу.                                                                                                                                                                                        |
| 11  | Удаление участника       | <span style="color:#2563eb">**Метод:**</span> [delete-member](../method/member/delete-member.md).<br><span style="color:#b45309">**Отправляем:**</span> `userId` удаляемого.<br><span style="color:#15803d">**Результат:**</span> участник исключается из группы.                                                                                                                                                                                                                                |
| 12  | Переименование группы    | <span style="color:#2563eb">**Метод:**</span> [patch-group-name](../method/conversation/patch-group-name.md).<br><span style="color:#b45309">**Отправляем:**</span> новое `name` (обрезанное).<br><span style="color:#15803d">**Результат:**</span> название группы обновляется.                                                                                                                                                                                                                |
| 13  | Покинуть группу          | <span style="color:#2563eb">**Метод:**</span> [leave-group](../method/member/leave-group.md).<br><span style="color:#15803d">**Результат:**</span> текущий пользователь выходит из группы; группа исчезает из его списка.                                                                                                                                                                                                                                                                        |
| 14  | Удалить группу           | <span style="color:#2563eb">**Метод:**</span> [delete-group-conversation](../method/conversation/delete-group-conversation.md).<br><span style="color:#15803d">**Результат:**</span> группа и её сообщения удаляются для всех участников.                                                                                                                                                                                                                                                        |

### Роли

|     | **Requirement**     | **Description**                                                                                                                                                                                                                                                                          |
| --- | ------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 1   | Две роли            | <span style="color:#0f766e">**Роли:**</span><br>* `owner` — создатель группы (определяется по `ownerId`);<br>* `member` — все остальные участники.                                                                                                                                       |
| 2   | Действия владельца  | Владелец может:<br>1. переименовать группу;<br>2. пригласить участников;<br>3. удалить любого участника (кроме себя);<br>4. удалить группу.<br><br>**Примечание:** владельцу вместо «покинуть группу» доступно «удалить группу».                                                            |
| 3   | Действия участника  | Участник (не владелец) может:<br>1. отправлять сообщения;<br>2. покинуть группу.<br><br>**Примечание:** приглашение и удаление участников, переименование — недоступны.                                                                                                                    |

### Шапка группы

|     | **Requirement**     | **Description**                                                                                                                                              |
| --- | ------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 1   | Карточка группы     | <span style="color:#0f766e">**Показываем:**</span><br>1. аватар группы<br>2. `name` — название<br>3. число участников                                        |
| 2   | Переход в инфо      | **Действие:** нажатие на карточку группы.<br><span style="color:#15803d">**Результат:**</span> открывается экран информации о группе (см. «Экран информации о группе»). |

### Сообщения

|     | **Requirement**     | **Description**                                                                                                                                                                                          |
| --- | ------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 1   | История             | **Порядок:** хронологический.<br>**Подгрузка:** более ранние сообщения подгружаются порциями при прокрутке к началу (см. «Данные и методы» → п. 4).                                                       |
| 2   | Отправитель         | <span style="color:#0f766e">**Показываем у каждого сообщения:**</span> имя и аватар отправителя (по `senderId` из списка участников).                                                                    |
| 3   | Отправка            | **Поле:** ввод текста.<br>**Поведение:** по отправке текст обрезается (`trim`); пустое сообщение не отправляется.<br><span style="color:#15803d">**Результат:**</span> сообщение появляется в конце ленты. |
| 4   | Статусы сообщения   | <span style="color:#0f766e">**Показываем:**</span><br>1. `sending` — отправляется<br>2. `sent` — отправлено                                                                                              |
| 5   | Ошибка отправки     | <span style="color:#b91c1c">**Ошибка:**</span> snackbar «Не удалось отправить сообщение, попробуйте снова».                                                                                              |
| 6   | Пустое состояние    | **Когда:** в группе ещё нет сообщений.<br>**Показываем:** аватар и название группы, число участников и приглашение начать переписку.                                                                      |
| 7   | Отсутствие веток    | В групповом чате веток нет — это плоская переписка.                                                                                                                                                       |

### Экран информации о группе

|     | **Requirement**       | **Description**                                                                                                                                                                                          |
| --- | --------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 1   | Состав экрана         | <span style="color:#0f766e">**Показываем:**</span><br>1. аватар и `name` группы<br>2. число участников<br>3. список участников (см. п. 2)<br>4. действия по роли (см. «Роли»)                              |
| 2   | Карточка участника    | <span style="color:#0f766e">**Показываем:**</span><br>1. аватар (`photoUrl`)<br>2. `displayName` — имя; для себя отметка «Вы» (`isMe`)<br>3. `email`<br>4. бейдж «Владелец» для владельца (`isOwner`)     |
| 3   | Назад из инфо         | **Действие:** «назад».<br><span style="color:#15803d">**Результат:**</span> возврат к ленте сообщений группы.                                                                                             |

### Переименование группы

|     | **Requirement**     | **Description**                                                                                                                                                                                       |
| --- | ------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 1   | Доступность         | Доступно только владельцу.<br>**Действие:** нажатие на иконку редактирования у названия → диалог переименования.                                                                                       |
| 2   | Ввод названия       | **Поле:** новое название (предзаполнено текущим).<br>**Кнопка подтверждения:** активна, если название после `trim` непустое и отличается от текущего.                                                  |
| 3   | Подтверждение       | <span style="color:#2563eb">**Метод:**</span> [patch-group-name](../method/conversation/patch-group-name.md) (см. «Данные и методы» → п. 12).<br><span style="color:#b91c1c">**Ошибка:**</span> snackbar «Что-то пошло не так, попробуйте снова». |

### Приглашение участников

|     | **Requirement**       | **Description**                                                                                                                                                                                                                                                                  |
| --- | --------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 1   | Доступность           | Доступно только владельцу.<br>**Действие:** «добавить участников» → форма поиска и выбора.                                                                                                                                                                                        |
| 2   | Поиск                 | **Поле:** поиск по email.<br>**Поведение:** запрос отправляется с задержкой после ввода; при пустом поле результаты очищаются.<br><span style="color:#2563eb">**Метод:**</span> [get-users-by-email-prefix](../method/user/get-users-by-email-prefix.md) (см. «Данные и методы» → п. 9). |
| 3   | Результаты и выбор    | <span style="color:#0f766e">**Показываем по кандидату:**</span> аватар, имя, email.<br>**Поведение:**<br>1. мультивыбор — можно отметить несколько;<br>2. уже состоящие в группе помечены «Уже в группе» и недоступны для выбора;<br>3. при достижении лимита группы (10 участников) новые отметить нельзя, показывается подсказка о лимите. |
| 4   | Подтверждение         | **Кнопка:** «Добавить (N)», активна при выбранном ≥ 1.<br><span style="color:#2563eb">**Метод:**</span> [post-invite-member](../method/member/post-invite-member.md) на каждого выбранного (см. «Данные и методы» → п. 10).<br><span style="color:#b91c1c">**Ошибка:**</span> snackbar «Что-то пошло не так, попробуйте снова». |

### Удаление участника

|     | **Requirement**     | **Description**                                                                                                                                                                                                            |
| --- | ------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 1   | Доступность         | Доступно только владельцу и только для других участников (не себя и не владельца).                                                                                                                                          |
| 2   | Удаление            | **Действие:** удаление участника → подтверждающий диалог.<br><span style="color:#2563eb">**Метод:**</span> [delete-member](../method/member/delete-member.md) (см. «Данные и методы» → п. 11).<br><span style="color:#b91c1c">**Ошибка:**</span> snackbar «Что-то пошло не так, попробуйте снова». |

### Выход и удаление группы

|     | **Requirement**     | **Description**                                                                                                                                                                                                                       |
| --- | ------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 1   | Покинуть группу     | **Доступность:** участник (не владелец).<br>**Действие:** «покинуть группу» → подтверждающий диалог.<br><span style="color:#2563eb">**Метод:**</span> [leave-group](../method/member/leave-group.md) (см. «Данные и методы» → п. 13).<br><span style="color:#15803d">**Результат:**</span> экран группы закрывается. |
| 2   | Удалить группу      | **Доступность:** владелец.<br>**Действие:** «удалить группу» → подтверждающий диалог.<br><span style="color:#2563eb">**Метод:**</span> [delete-group-conversation](../method/conversation/delete-group-conversation.md) (см. «Данные и методы» → п. 14).<br><span style="color:#15803d">**Результат:**</span> экран группы закрывается. |
| 3   | Ошибка операции     | <span style="color:#b91c1c">**Ошибка (выход / удаление):**</span> snackbar «Что-то пошло не так, попробуйте снова»; пользователь остаётся на экране.                                                                                   |

## Requirements

|    | **Requirement**       | **Description**                                                                                                                                   |
|----|-----------------------|---------------------------------------------------------------------------------------------------------------------------------------------------|
|  1 | Метод входа           | Единственный способ войти — кнопка Google Sign-In. Ручная регистрация и вход по паролю отсутствуют.                                               |
|  2 | Роутинг при запуске   | При запуске приложение проверяет состояние сессии: 1. Если сессия активна — открывается `conversation-list`. 2. Если сессия неактивна — открывается экран входа. |
|  3 | Сохранение сессии     | После успешного входа сессия сохраняется между перезапусками приложения. Пользователь не переходит на экран входа, пока сессия действительна.     |
|  4 | Выход                 | Выйти из аккаунта можно через `profile`. После выхода сессия завершается, локальные данные очищаются, приложение возвращается на экран входа.      |

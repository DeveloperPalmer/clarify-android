## Requirements

### Данные и методы

Авторизация работает с провайдером входа (Google) и с сессией пользователя через методы доступа к данным. Требования описывают только публичный контракт каждой операции — что платформа **отправляет** и что **получает** в ответ.

|     | **Requirement**            | **Description**                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                        |
| --- | -------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 1   | Проверка сессии при старте | **Когда:** при запуске приложения, до показа любого экрана.<br><span style="color:#2563eb">**Метод:**</span> наблюдение за состоянием сессии (`observe-session-state`).<br><span style="color:#0f766e">**Получаем:**</span> состояние сессии — `active` / `inactive` (см. п. 2).                                                                                                                                                                                                                                                                                                                                                                                                                                       |
| 2   | Состояние сессии           | <span style="color:#0f766e">**Получаем:**</span> состояние сессии:<br>* `active` — есть активная сессия с действующими токенами;<br>* `inactive` — активной сессии нет (никогда не входил, вышел или токены отсутствуют).<br><br>**Зачем:** определяет стартовый экран (см. «Маршрутизация при запуске»).                                                                                                                                                                                                                                                                                                                                                                                                |
| 3   | Вход через провайдера      | <span style="color:#2563eb">**Метод:**</span> вход через Google (`sign-in-by-google`).<br><span style="color:#b45309">**Отправляем:**</span> ничего — платформа инициирует системный выбор Google-аккаунта.<br><span style="color:#0f766e">**Получаем (идентичность пользователя):**</span><br>1. `userId`<br>2. `email`<br>3. `displayName`<br>4. `photoUrl`<br>5. токены сессии<br><br><span style="color:#b91c1c">**Либо:**</span><br>1. «отмена пользователем»<br>2. «ошибка аутентификации»                                                                                                                                                                                                                       |
| 4   | Учётная запись             | **Когда:** после успешного входа через провайдера.<br><span style="color:#2563eb">**Метод (проверка):**</span> [get-user-exists](../method/user/get-user-exists.md) — есть ли уже учётная запись.<br><br>**Развилка по результату проверки:**<br>1. **не существует** → <span style="color:#2563eb">**Метод:**</span> [post-user](../method/user/post-user.md) — учётная запись создаётся;<br>2. **существует** → <span style="color:#2563eb">**Метод:**</span> [patch-user](../method/user/patch-user.md) — переданные данные профиля обновляются под актуальные из Google.<br><br><span style="color:#b45309">**Отправляем (в обе ветки):**</span><br>1. `userId`<br>2. `email`<br>3. `displayName`<br>4. `photoUrl` |
| 5   | Старт сессии               | **Когда:** после успешного входа.<br><span style="color:#2563eb">**Метод:**</span> старт новой сессии (`start-session`).<br><span style="color:#b45309">**Отправляем:**</span><br>1. `userId`<br>2. токены сессии<br><span style="color:#15803d">**Результат:**</span> сессия становится `active` и сохраняется для последующих запусков.                                                                                                                                                                                                                                                                                                                                                                              |

### Маршрутизация при запуске

|     | **Requirement**  | **Description**                                                                                                                                                                              |
| --- | ---------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 1   | Чтение состояния | **Когда:** при запуске.<br>**Платформа:** один раз читает текущее состояние сессии (см. «Данные и методы» → п. 1–2) и по нему выбирает стартовый экран.                                      |
| 2   | Сессия активна   | <span style="color:#0f766e">**Состояние:**</span> `active`.<br><span style="color:#15803d">**Результат:**</span> открывается главный экран — фича [chat-conversation](chat-conversation.md). |
| 3   | Сессия неактивна | <span style="color:#0f766e">**Состояние:**</span> `inactive`.<br><span style="color:#15803d">**Результат:**</span> открывается экран входа.                                                  |

### Экран входа

|    | **Requirement**       | **Description**                                                                                                                                                                       |
|----|-----------------------|-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|  1 | Способ входа          | Единственный рабочий способ войти — кнопка **Google Sign-In**. Ручная регистрация и вход по паролю отсутствуют.                                                                       |
|  2 | Вход по email         | **Статус:** не реализован.<br>**Поведение:** при нажатии показывается уведомление «функция пока недоступна»; вход не выполняется.                                                       |
|  3 | Защита от повторного входа | **Когда:** вход через Google уже выполняется.<br>**Поведение:**<br>1. на время входа показывается индикатор выполнения;<br>2. повторное нажатие не запускает второй вход.            |
|  4 | Назад с экрана входа  | **Действие:** «назад».<br><span style="color:#15803d">**Результат:**</span> выход из приложения (флоу завершается).                                                                    |

### Вход через Google

|    | **Requirement**       | **Description**                                                                                                                                                                                                                                                              |
|----|-----------------------|---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|  1 | Запуск входа          | **Действие:** нажатие кнопки Google Sign-In.<br><span style="color:#2563eb">**Метод:**</span> вход через Google (см. «Данные и методы» → п. 3).<br>**Поведение:** открывается системный выбор Google-аккаунта.                                                                |
|  2 | Успешный вход         | <span style="color:#15803d">**Результат:**</span> по порядку:<br>1. учётная запись создаётся/обновляется (п. 4 «Данные и методы»);<br>2. стартует сессия (п. 5);<br>3. экран входа закрывается, открывается фича [chat-conversation](chat-conversation.md).                    |
|  3 | Отмена пользователем  | <span style="color:#b91c1c">**Ошибка (отмена):**</span> пользователь закрыл выбор аккаунта.<br>**Поведение:** ничего не происходит — сообщение не показывается, пользователь остаётся на экране входа.                                                                          |
|  4 | Ошибка аутентификации | <span style="color:#b91c1c">**Ошибка (прочее):**</span> сбой входа или получения данных аккаунта.<br>**Поведение:** показывается уведомление об ошибке, пользователь остаётся на экране входа; сессия не стартует.                                                              |

### Сохранение сессии

|     | **Requirement**            | **Description**                                                                                                                                                      |
| --- | -------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 1   | Сохранение между запусками | После успешного входа сессия сохраняется. При следующих запусках состояние читается как `active`, и пользователь сразу попадает на главный экран, минуя экран входа. |
| 2   | Срок действия              | Пока сессия `active`, экран входа не показывается. Сессия становится `inactive` после выхода из аккаунта.                |

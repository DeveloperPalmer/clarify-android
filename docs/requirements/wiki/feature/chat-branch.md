## Requirements

### Данные и методы

Данные экрана платформа получает через методы доступа к данным (раздел `method`). Требования описывают только публичный контракт каждого метода — что платформа **отправляет** и что **получает** в ответ. Что находится за интерфейсом метода (хранилище, бэкенд, кэш) требованиями не рассматривается.

Ветка открывается с уже известным идентификатором из личной переписки; её создание описано в вызывающей фиче, а не здесь.

|     | **Requirement**          | **Description**                                                                                                                                                                                                                                                                                                                                                                                                                                          |
| --- | ------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 1   | Загрузка при открытии    | **Когда:** при открытии экрана.<br>**Платформа подписывается и догружает:**<br>1. [observe-branches](../method/branch/observe-branches.md) — состояние ветки и её merge request<br>2. [observe-commits](../method/commit/observe-commits.md) — живой поток сообщений ветки<br>3. [observe-branch-unread-count](../method/unread-count/observe-branch-unread-count.md) — счётчик непрочитанных ветки<br>4. [observe-unread-count](../method/unread-count/observe-unread-count.md) — счётчик непрочитанных<br>5. [observe-member](../method/member/observe-member.md) — отметка прочтения собеседника<br>6. [get-commits](../method/commit/get-commits.md) — первая порция истории |
| 2   | Состояние ветки          | <span style="color:#2563eb">**Метод:**</span> [observe-branches](../method/branch/observe-branches.md).<br><span style="color:#0f766e">**Получаем по ветке:**</span><br>1. `name` — название<br>2. `mergeRequest` — merge request ветки либо его отсутствие (см. «Merge request»)                                                                                                                                                                          |
| 3   | Поток сообщений          | <span style="color:#2563eb">**Метод:**</span> [observe-commits](../method/commit/observe-commits.md).<br><span style="color:#0f766e">**Получаем:**</span> живой поток сообщений ветки.<br><br>Каждая эмиссия — изменения `added` / `modified` / `removed`.                                                                                                                                                                                                  |
| 4   | Поля сообщения           | <span style="color:#0f766e">**Получаем по каждому сообщению:**</span><br>1. `id` — идентификатор<br>2. `senderId` — UID отправителя<br>3. `text` — текст<br>4. `timestamp` — время отправки<br>5. `status` — `sending` / `sent`<br>6. `isSelf` — отправлено текущим пользователем<br>7. признак прочтения собеседником (по его отметке прочтения, см. п. 9)                                                                          |
| 5   | Подгрузка истории        | <span style="color:#2563eb">**Метод:**</span> [get-commits](../method/commit/get-commits.md).<br><span style="color:#b45309">**Отправляем:**</span><br>1. `count` — размер порции<br>2. `before` — граница: сообщения раньше указанного<br><span style="color:#0f766e">**Получаем:**</span> порцию более ранних сообщений ветки.                                                                                                                            |
| 6   | Отправка сообщения       | <span style="color:#2563eb">**Метод:**</span> [post-branch-commit](../method/commit/post-branch-commit.md).<br><span style="color:#b45309">**Отправляем:**</span><br>1. `text` — текст (обрезанный)<br><span style="color:#15803d">**Результат:**</span> сообщение появляется в конце ленты ветки.<br><br>**Ограничение:** отправка возможна только пока у ветки нет merge request (см. «Заморозка ветки»).                            |
| 7   | Счётчик непрочитанных    | <span style="color:#2563eb">**Метод:**</span> [observe-unread-count](../method/unread-count/observe-unread-count.md), [observe-branch-unread-count](../method/unread-count/observe-branch-unread-count.md).<br><span style="color:#0f766e">**Получаем:**</span> живой счётчик непрочитанных; `0`, если непрочитанных нет.                                                                                                                                    |
| 8   | Отметка прочтения        | **Когда:** при открытии и при просмотре сообщений.<br>**Платформа вызывает:**<br>1. [patch-branch-clear-unread-count](../method/unread-count/patch-branch-clear-unread-count.md) — обнуляет счётчик непрочитанных ветки при открытии<br>2. [patch-read-watermark](../method/member/patch-read-watermark.md) — сдвигает отметку прочтения до времени последнего просмотренного сообщения<br>3. [patch-clear-unread-count](../method/unread-count/patch-clear-unread-count.md) — обнуляет счётчик непрочитанных |
| 9   | Отметка прочтения собеседником | <span style="color:#2563eb">**Метод:**</span> [observe-member](../method/member/observe-member.md).<br><span style="color:#0f766e">**Получаем:**</span> момент последнего прочтения собеседником — по нему свои сообщения помечаются прочитанными (отметки прочтения общие для всей переписки, включая ветки).                                                                                                                                          |
| 10  | Открытие merge request   | <span style="color:#2563eb">**Метод:**</span> [post-merge-request](../method/merge-request/post-merge-request.md).<br><span style="color:#15803d">**Результат:**</span> у ветки появляется merge request в статусе `open`.                                                                                                                                                                                                                                 |
| 11  | Одобрение                | <span style="color:#2563eb">**Метод:**</span> [patch-merge-approval](../method/merge-request/patch-merge-approval.md).<br><span style="color:#15803d">**Результат:**</span> текущий пользователь добавляется в одобрившие; когда одобрили все участники — статус становится `readyToMerge`.                                                                                                                                                                  |
| 12  | Отзыв одобрения          | <span style="color:#2563eb">**Метод:**</span> [delete-merge-approval](../method/merge-request/delete-merge-approval.md).<br><span style="color:#15803d">**Результат:**</span> одобрение текущего пользователя снимается; статус возвращается в `open`.                                                                                                                                                                                                      |
| 13  | Отмена merge request     | <span style="color:#2563eb">**Метод:**</span> [delete-merge-request](../method/merge-request/delete-merge-request.md).<br><span style="color:#15803d">**Результат:**</span> merge request удаляется, ветка размораживается.                                                                                                                                                                                                                                |
| 14  | Финализация слияния      | <span style="color:#2563eb">**Метод:**</span> [patch-merge-finalize](../method/merge-request/patch-merge-finalize.md).<br><span style="color:#15803d">**Результат:**</span> статус становится `merged` — финальный, ветка переходит в режим только чтения.                                                                                                                                                                                                 |

### Шапка ветки

|     | **Requirement**     | **Description**                                                                                                                                                       |
| --- | ------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 1   | Название ветки      | <span style="color:#0f766e">**Показываем:**</span> `name` ветки (если пусто — название по умолчанию).                                                                |
| 2   | Кнопка merge request | **Показываем:** кнопку со статусом merge request (см. «Merge request → Статусы»).<br>**Действие:** нажатие открывает карточку merge request (кроме статуса `merged`). |

### Сообщения

|     | **Requirement**     | **Description**                                                                                                                                                                                          |
| --- | ------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 1   | История             | **Порядок:** хронологический.<br>**Подгрузка:** более ранние сообщения подгружаются порциями при прокрутке к началу (см. «Данные и методы» → п. 5).                                                       |
| 2   | Отправка            | **Поле:** ввод текста.<br>**Поведение:** по отправке текст обрезается (`trim`); пустое сообщение не отправляется.<br>**Доступность:** только пока у ветки нет merge request (см. «Заморозка ветки»).        |
| 3   | Статусы сообщения   | <span style="color:#0f766e">**Показываем:**</span><br>1. `sending` — отправляется<br>2. `sent` — отправлено<br>3. признак прочтения собеседником                                                          |
| 4   | Прокрутка к новым   | **Показываем:** кнопку перехода к последним сообщениям со счётчиком непрочитанных.                                                                                                                        |
| 5   | Пустое состояние    | **Когда:** в ветке ещё нет сообщений.<br>**Показываем:** заглушку с приглашением начать ветку.                                                                                                            |

### Непрочитанные

|     | **Requirement**     | **Description**                                                                                                                                                  |
| --- | ------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 1   | Отметка прочтения   | **Когда:** при открытии ветки и при просмотре сообщений.<br>**Поведение:** платформа сдвигает отметку прочтения и обнуляет счётчики (см. «Данные и методы» → п. 8). |
| 2   | Независимость ветки | Счётчик непрочитанных ветки ведётся отдельно от основного треда переписки.                                                                                        |

### Merge request

|     | **Requirement**     | **Description**                                                                                                                                                                                                                                                  |
| --- | ------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 1   | Статусы             | <span style="color:#0f766e">**Статус merge request:**</span><br>* отсутствует — merge request не открыт, кнопка предлагает открыть;<br>* `open` — открыт, идёт сбор одобрений;<br>* `readyToMerge` — одобрен всеми участниками, доступна финализация;<br>* `merged` — слияние завершено, статус финальный. |
| 2   | Доступность действий | Действия с merge request доступны участникам ветки. Защита от повторного запуска: пока операция выполняется, показывается индикатор, повторное действие не запускает её второй раз.                                                                              |
| 3   | Открыть             | **Когда:** merge request отсутствует.<br>**Действие:** нажатие кнопки → открытие (см. «Данные и методы» → п. 10).<br><span style="color:#b91c1c">**Ошибка:**</span> snackbar «Не удалось открыть merge request».                                                  |
| 4   | Одобрить            | **Когда:** статус `open` или `readyToMerge` и пользователь ещё не одобрил.<br>**Действие:** одобрить (см. «Данные и методы» → п. 11).<br><span style="color:#b91c1c">**Ошибка:**</span> snackbar «Не удалось одобрить мердж».                                      |
| 5   | Отозвать одобрение  | **Когда:** статус `open` или `readyToMerge` и пользователь уже одобрил.<br>**Действие:** отозвать одобрение (см. «Данные и методы» → п. 12).<br><span style="color:#b91c1c">**Ошибка:**</span> snackbar «Не удалось отозвать одобрение».                           |
| 6   | Отменить            | **Когда:** статус `open` или `readyToMerge`.<br>**Действие:** отменить merge request (см. «Данные и методы» → п. 13).<br><span style="color:#b91c1c">**Ошибка:**</span> snackbar «Не удалось отменить merge request».                                             |
| 7   | Финализировать      | **Когда:** статус `readyToMerge`.<br>**Действие:** завершить слияние (см. «Данные и методы» → п. 14).<br><span style="color:#b91c1c">**Ошибка:**</span> snackbar «Не удалось завершить мердж».                                                                    |

### Карточка merge request

|     | **Requirement**     | **Description**                                                                                                                                                                                          |
| --- | ------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 1   | Открытие карточки   | **Действие:** нажатие на кнопку merge request (кроме статуса `merged`).<br>**Показываем:** карточку с составом одобрений и действиями.                                                                    |
| 2   | Состав карточки     | <span style="color:#0f766e">**Показываем:**</span><br>1. участников ветки с отметкой «одобрил / не одобрил»<br>2. счётчик «одобрили N из M»<br>3. кнопку «одобрить» либо «отозвать одобрение» (по своему статусу)<br>4. кнопку «смерджить» при статусе `readyToMerge`<br>5. кнопку отмены merge request<br>6. имя инициатора |

### Заморозка ветки

|     | **Requirement**     | **Description**                                                                                                                                                                          |
| --- | ------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 1   | Активный merge request | **Когда:** статус `open` или `readyToMerge`.<br>**Поведение:** поле ввода скрыто, вместо него — «Ветка заблокирована, пока открыт merge request»; отправка недоступна.                  |
| 2   | Смерджена           | **Когда:** статус `merged`.<br>**Поведение:** ветка в режиме только чтения — «Эта ветка смерджена (только чтение)»; отправка и действия merge request недоступны.                         |

### Навигация

|     | **Requirement**     | **Description**                                                                                                          |
| --- | ------------------- | ----------------------------------------------------------------------------------------------------------------------- |
| 1   | Назад из ветки      | **Действие:** «назад».<br>**Поведение:** если открыта карточка merge request — она закрывается; иначе ветка закрывается и платформа возвращается на предыдущий экран. |

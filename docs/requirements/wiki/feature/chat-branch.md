# Chat-Branch

**Summary**: Ветка (подтред) внутри личной переписки — собственная история сообщений, контекстное меню сообщения (копировать / выбрать / удалить), удаление сообщений «у себя» и «у всех» и процесс слияния через merge request: открытие, одобрение участниками, отмена и финализация.

## Requirements

### Данные и методы

Данные экрана платформа получает через методы доступа к данным (раздел `method`). Требования описывают только публичный контракт каждого метода — что платформа **отправляет** и что **получает** в ответ. Что находится за интерфейсом метода (хранилище, бэкенд, кэш) требованиями не рассматривается.

Ветка открывается с уже известным идентификатором из личной переписки; её создание описано в вызывающей фиче, а не здесь.

|     | **Requirement**          | **Description**                                                                                                                                                                                                                                                                                                                                                                                                                                          |
| --- | ------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 1   | Загрузка при открытии    | **Когда:** при открытии экрана.<br>**Платформа подписывается и догружает:**<br>1. [branch-live](../method/branch/branch-live.md) — состояние ветки и её merge request<br>2. [commits-tail-live](../method/commit/commits-tail-live.md) — живой поток сообщений ветки<br>3. [branch-unread-count-live](../method/unread-count/branch-unread-count-live.md) — счётчик непрочитанных ветки<br>4. [unread-count-live](../method/unread-count/unread-count-live.md) — счётчик непрочитанных<br>5. [member-live](../method/member/member-live.md) — отметка прочтения собеседника<br>6. [read-commits](../method/commit/read-commits.md) — первая порция истории |
| 2   | Состояние ветки          | <span style="color:#2563eb">**Метод:**</span> [branch-live](../method/branch/branch-live.md).<br><span style="color:#0f766e">**Получаем по ветке:**</span><br>1. `name` — название<br>2. `mergeRequest` — merge request ветки либо его отсутствие (см. «Merge request»)<br><br>**Примечание:** метод отдаёт одну ветку, а не список: экрану нужна только та, что открыта. Отсутствие ветки означает, что она удалена, — экран убирает её из истории.                                                                                                                                                                          |
| 3   | Поток сообщений          | <span style="color:#2563eb">**Метод:**</span> [commits-tail-live](../method/commit/commits-tail-live.md).<br><span style="color:#b45309">**Отправляем:**</span><br>1. `from` — курсор самого раннего загруженного сообщения<br><span style="color:#0f766e">**Получаем:**</span> живой поток сообщений ветки от курсора и дальше.<br><br>Каждая эмиссия — изменения `added` / `modified` / `removed`.<br><br>**Примечание:** подписка открывается после первой порции истории (см. п. 5) — от самого раннего загруженного сообщения; всё, что старее, догружается порциями и в подписку не входит.                                                                                                                                                                                                  |
| 4   | Поля сообщения           | <span style="color:#0f766e">**Получаем по каждому сообщению:**</span><br>1. `id` — идентификатор<br>2. `senderId` — UID отправителя<br>3. `text` — текст<br>4. `timestamp` — время отправки<br>5. `status` — `sending` / `sent`<br>6. `isSelf` — отправлено текущим пользователем<br>7. `editedAt` — момент правки; `null`, если сообщение не редактировалось<br>8. `replyCommit` — снапшот цитируемого сообщения (`id`, `senderUid`, `text`); `null`, если сообщение не является ответом<br>9. признак прочтения собеседником (по его отметке прочтения, см. п. 9)                                                                          |
| 5   | Подгрузка истории        | <span style="color:#2563eb">**Метод:**</span> [read-commits](../method/commit/read-commits.md).<br><span style="color:#b45309">**Отправляем:**</span><br>1. `limit` — размер порции<br>2. `before` — курсор: сообщения раньше него<br><span style="color:#0f766e">**Получаем:**</span> порцию более ранних сообщений ветки.                                                                                                                            |
| 6   | Отправка сообщения       | <span style="color:#2563eb">**Метод:**</span> [create-branch-commit](../method/commit/create-branch-commit.md).<br><span style="color:#b45309">**Отправляем:**</span><br>1. `text` — текст (обрезанный)<br>2. `replyCommit` — снапшот цитируемого сообщения (`id`, `senderUid`, `text`); `null` — обычное сообщение<br><span style="color:#15803d">**Результат:**</span> сообщение появляется в конце ленты ветки.<br><br>**Ограничение:** отправка возможна только пока у ветки нет merge request (см. «Заморозка ветки»).                            |
| 7   | Счётчик непрочитанных    | <span style="color:#2563eb">**Метод:**</span> [unread-count-live](../method/unread-count/unread-count-live.md), [branch-unread-count-live](../method/unread-count/branch-unread-count-live.md).<br><span style="color:#0f766e">**Получаем:**</span> живой счётчик непрочитанных; `0`, если непрочитанных нет.                                                                                                                                    |
| 8   | Отметка прочтения        | **Когда:** при открытии и при просмотре сообщений.<br>**Платформа вызывает:**<br>1. [update-branch-unread-count](../method/unread-count/update-branch-unread-count.md) — обнуляет счётчик непрочитанных ветки при открытии<br>2. [update-read-watermark](../method/member/update-read-watermark.md) — сдвигает отметку прочтения до времени последнего просмотренного сообщения<br>3. [update-unread-count](../method/unread-count/update-unread-count.md) — обнуляет счётчик непрочитанных |
| 9   | Отметка прочтения собеседником | <span style="color:#2563eb">**Метод:**</span> [member-live](../method/member/member-live.md).<br><span style="color:#0f766e">**Получаем:**</span> момент последнего прочтения собеседником — по нему свои сообщения помечаются прочитанными (отметки прочтения общие для всей переписки, включая ветки).                                                                                                                                          |
| 10  | Открытие merge request   | <span style="color:#2563eb">**Метод:**</span> [create-open-merge-request](../method/merge-request/create-open-merge-request.md).<br><span style="color:#15803d">**Результат:**</span> у ветки появляется merge request в статусе `open`.                                                                                                                                                                                                                                 |
| 11  | Одобрение                | <span style="color:#2563eb">**Метод:**</span> [update-merge-approval](../method/merge-request/update-merge-approval.md).<br><span style="color:#15803d">**Результат:**</span> текущий пользователь добавляется в одобрившие; когда одобрили все участники — статус становится `readyToMerge`.                                                                                                                                                                  |
| 12  | Отзыв одобрения          | <span style="color:#2563eb">**Метод:**</span> [delete-merge-request-approval](../method/merge-request/delete-merge-request-approval.md).<br><span style="color:#15803d">**Результат:**</span> одобрение текущего пользователя снимается; статус возвращается в `open`.                                                                                                                                                                                                      |
| 13  | Отмена merge request     | <span style="color:#2563eb">**Метод:**</span> [delete-merge-request](../method/merge-request/delete-merge-request.md).<br><span style="color:#15803d">**Результат:**</span> merge request удаляется, ветка размораживается.                                                                                                                                                                                                                                |
| 14  | Финализация слияния      | <span style="color:#2563eb">**Метод:**</span> [update-merge-finalize](../method/merge-request/update-merge-finalize.md).<br><span style="color:#15803d">**Результат:**</span> статус становится `merged` — финальный, ветка переходит в режим только чтения.                                                                                                                                                                                                 |
| 15  | Скрытие сообщений «у себя»  | <span style="color:#2563eb">**Метод:**</span> [hide-commits](../method/commit/hide-commits.md).<br><span style="color:#b45309">**Отправляем:**</span><br>1. `commitIds` — выбранные сообщения<br><span style="color:#15803d">**Результат:**</span> сообщения пропадают у текущего пользователя; у собеседника остаются. |
| 16  | Удаление сообщений «у всех» | <span style="color:#2563eb">**Метод:**</span> [delete-branch-commits](../method/commit/delete-branch-commits.md).<br><span style="color:#b45309">**Отправляем:**</span><br>1. `commitIds` — выбранные сообщения<br>2. `lastCommit` — пересчитанное последнее сообщение ветки: keep / replace / clear<br>3. `peerUnreadDelta` — на сколько уменьшить счётчик непрочитанных ветки у собеседника<br><span style="color:#15803d">**Результат:**</span> сообщения удаляются у обоих участников; при необходимости обновляются превью последнего сообщения ветки и счётчик непрочитанных собеседника. |
| 17  | Редактирование сообщения | <span style="color:#2563eb">**Метод:**</span> [update-branch-commit](../method/commit/update-branch-commit.md).<br><span style="color:#b45309">**Отправляем:**</span><br>1. `commitId` — редактируемое сообщение<br>2. `text` — новый текст (обрезанный)<br><span style="color:#0f766e">**Получаем:**</span> у сообщения появляется `editedAt`.<br><span style="color:#15803d">**Результат:**</span> текст заменён у обоих участников; время отправки не меняется; при правке последнего сообщения ветки обновляется её превью.<br><span style="color:#b91c1c">**Ошибка:**</span> сообщение уже удалено «у всех» — режим сбрасывается (см. «Редактирование» → п. 6). |

### Шапка ветки

|     | **Requirement**     | **Description**                                                                                                                                                       |
| --- | ------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 1   | Название ветки      | <span style="color:#0f766e">**Показываем:**</span> `name` ветки (если пусто — название по умолчанию).                                                                |
| 2   | Кнопка merge request | **Показываем:** кнопку со статусом merge request (см. «Merge request → Статусы»).<br>**Действие:** нажатие открывает карточку merge request (кроме статуса `merged`). |

### Сообщения

|     | **Requirement**     | **Description**                                                                                                                                                                                          |
| --- | ------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 1   | История             | **Порядок:** хронологический.<br>**Подгрузка:** более ранние сообщения подгружаются порциями при прокрутке к началу (см. «Данные и методы» → п. 5).                                                       |
| 2   | Отправка            | **Поле:** ввод текста.<br>**Поведение:** по отправке текст обрезается (`trim`); пустое сообщение не отправляется.<br>**Доступность:** только пока у ветки нет merge request (см. «Заморозка ветки»).        |
| 3   | Статусы сообщения   | <span style="color:#0f766e">**Показываем:**</span><br>1. `sending` — отправляется<br>2. `sent` — отправлено<br>3. признак прочтения собеседником                                                          |
| 4   | Прокрутка к новым   | **Показываем:** кнопку перехода к последним сообщениям со счётчиком непрочитанных.                                                                                                                        |
| 5   | Пустое состояние    | **Когда:** в ветке ещё нет сообщений.<br>**Показываем:** заглушку с приглашением начать ветку.                                                                                                            |

### Контекстное меню сообщения

|     | **Requirement**   | **Description**                                                                                                                                                                                                     |
| --- | ----------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| 1   | Открытие меню     | **Действие:** нажатие на сообщение вне режима выбора.<br>**Поведение:** перед показом скрывается клавиатура; меню приякорено к сообщению; лента затемняется.                                                          |
| 2   | Пункты меню       | <span style="color:#0f766e">**Показываем:**</span><br>1. ответить<br>2. редактировать — только у своих сообщений<br>3. копировать<br>4. выбрать<br>5. удалить<br><br>**Примечание:** пункта «создать ветку» здесь нет — вложенных веток не бывает, ветки создаются только в личной переписке. |
| 2.1 | Ответить          | **Действие:** пункт «ответить» (доступен для любого сообщения — своего и чужого).<br><span style="color:#15803d">**Результат:**</span> меню закрывается, экран переходит в режим ответа на это сообщение (см. «Ответ на сообщение»).                                                       |
| 2.2 | Редактировать     | **Действие:** пункт «редактировать» (виден только у своих сообщений).<br><span style="color:#15803d">**Результат:**</span> меню закрывается, экран переходит в режим редактирования этого сообщения (см. «Редактирование»).                                                              |
| 3   | Копировать        | **Действие:** пункт «копировать».<br><span style="color:#15803d">**Результат:**</span> текст сообщения копируется в буфер обмена; меню закрывается; показывается snackbar «Скопировано».                                |
| 4   | Выбрать           | **Действие:** пункт «выбрать».<br><span style="color:#15803d">**Результат:**</span> меню закрывается, экран переходит в режим выбора с этим сообщением (см. «Выбор и удаление»).                                        |
| 5   | Удалить           | **Действие:** пункт «удалить».<br><span style="color:#15803d">**Результат:**</span> меню закрывается, показывается диалог удаления для этого сообщения (см. «Выбор и удаление» → пп. 5–8).                              |
| 6   | Закрытие меню     | **Действие:** нажатие по затемнению или системная кнопка «назад».<br><span style="color:#15803d">**Результат:**</span> меню закрывается без изменений.                                                                 |

### Ответ на сообщение

|     | **Requirement**            | **Description**                                                                                                                                                                                                                                                                                                          |
| --- | -------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| 1   | Вход в режим               | **Действие:** пункт «ответить» контекстного меню (см. «Контекстное меню сообщения» → п. 2.1).<br><span style="color:#0f766e">**Показываем:**</span> шапку над полем ввода — заголовок «Ответ · <имя автора>», сниппет цитируемого сообщения (1 строка) и крестик; поле получает фокус. Набранный до этого текст **сохраняется**. |
| 2   | Имя автора цитаты          | Свои сообщения подписываются «Вы», чужие — именем участника ветки. Имя берётся актуальное, а не сохранённое в момент ответа.                                                                                                                                                                                              |
| 3   | Отправка                   | <span style="color:#2563eb">**Метод:**</span> [create-branch-commit](../method/commit/create-branch-commit.md) (см. «Данные и методы» → п. 6) — вместе с текстом уходит снапшот цитаты.<br><span style="color:#15803d">**Результат:**</span> сообщение появляется в конце ленты ветки с цитатой внутри пузыря; режим ответа снимается сразу. |
| 4   | Цитата в пузыре            | <span style="color:#0f766e">**Показываем:**</span> над текстом ответа — имя автора оригинала и одну строку его текста. Цитата хранит снапшот, поэтому остаётся читаемой после правки и удаления оригинала. |
| 5   | Переход к оригиналу        | **Действие:** нажатие на цитату.<br><span style="color:#15803d">**Результат:**</span> лента прокручивается к оригиналу и он ненадолго подсвечивается. Если оригинала нет среди загруженных сообщений — ничего не происходит. |
| 6   | Отмена                     | **Действие:** крестик в шапке или системная кнопка «назад».<br><span style="color:#15803d">**Результат:**</span> режим сбрасывается, набранный текст остаётся в поле. |
| 7   | Цель удалена               | **Когда:** цитируемое сообщение удалено, пока режим открыт.<br><span style="color:#15803d">**Результат:**</span> режим сбрасывается, показывается snackbar «Сообщение удалено». |
| 8   | Заморозка ветки            | При открытом merge request поле ввода недоступно (см. «Заморозка ветки»), поэтому режим ответа в замороженной ветке не открывается. |
| 9   | Взаимодействие с правкой   | Ответ и редактирование взаимоисключающие: вход в один режим снимает другой. |

### Редактирование

|     | **Requirement**            | **Description**                                                                                                                                                                                                                                                                                                          |
| --- | -------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| 1   | Вход в режим               | **Действие:** пункт «редактировать» контекстного меню (см. «Контекстное меню сообщения» → п. 2.2); доступен только у своих сообщений.<br><span style="color:#0f766e">**Показываем:**</span> шапку над полем ввода — заголовок «Редактировать сообщение», сниппет оригинала (1 строка) и крестик; поле заполняется текстом оригинала; кнопка отправки становится галочкой. Набранный до этого текст перезаписывается, черновики не сохраняются. |
| 2   | Валидация                  | Кнопка отправки неактивна, если текст после `trim` пуст или совпадает с оригиналом. Пустой текст не превращается в удаление. При пустом поле показывается подсказка «Сообщение не может быть пустым».                                                                                                                       |
| 3   | Отправка                   | <span style="color:#2563eb">**Метод:**</span> [update-branch-commit](../method/commit/update-branch-commit.md) (см. «Данные и методы» → п. 17).<br><span style="color:#15803d">**Результат:**</span> режим закрывается сразу, не дожидаясь ответа сервера: сообщение показывает новый текст со статусом `sending`, затем `sent`. Время отправки и позиция в истории не меняются; рядом со временем появляется метка «изменено». |
| 4   | Отмена                     | **Действие:** крестик в шапке.<br><span style="color:#15803d">**Результат:**</span> режим сбрасывается, поле очищается, сообщение остаётся прежним.                                                                                                                                                                        |
| 5   | Кнопка «назад»             | Режим редактирования, в отличие от режима ответа, не перехватывает системную кнопку «назад»: она закрывает экран, режим исчезает вместе с ним. Режим выбора при этом перехватывает «назад» независимо (см. «Выбор и удаление» → п. 4).                                                                                       |
| 6   | Цель удалена               | **Когда:** редактируемое сообщение удалено — локально, собеседником или обнаружено при отправке.<br><span style="color:#15803d">**Результат:**</span> режим сбрасывается, поле очищается, показывается snackbar «Сообщение удалено».                                                                                        |
| 7   | Ошибка отправки            | <span style="color:#b91c1c">**Ошибка:**</span> snackbar «Не удалось изменить сообщение, попробуйте снова»; прежний текст сообщения возвращается в ленту.                                                                                                                                                                   |
| 8   | Синхронизация              | Правка, выполненная собеседником или на другом устройстве, обновляет текст и метку «изменено» в ленте вживую (см. «Данные и методы» → п. 3, изменения `modified`).                                                                                                                                                          |
| 9   | Заморозка ветки            | При открытом merge request поле ввода недоступно (см. «Заморозка ветки»), поэтому режим редактирования в замороженной ветке не открывается.                                                                                                                                                                                |

### Выбор и удаление

|     | **Requirement**        | **Description**                                                                                                                                                                                                                                                                            |
| --- | ---------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 1   | Вход в режим выбора    | **Действие:** долгое нажатие на сообщение.<br>**Поведение:** экран переходит в режим выбора, сообщение отмечается выбранным.                                                                                                                                                               |
| 2   | Переключение выбора    | **Действие:** нажатие на сообщение в режиме выбора.<br>**Поведение:** добавляет или снимает отметку выбора. Выбирать можно как свои сообщения, так и сообщения собеседника.                                                                                                                 |
| 3   | Шапка выбора           | <span style="color:#0f766e">**Показываем:**</span><br>1. счётчик выбранных сообщений<br>2. кнопку закрытия режима выбора<br>3. кнопку удаления.                                                                                                                                            |
| 4   | Выход из режима выбора  | **Действие:** кнопка закрытия в шапке или системная кнопка «назад».<br><span style="color:#15803d">**Результат:**</span> выбор сбрасывается, экран возвращается в обычный режим.                                                                                                            |
| 5   | Диалог удаления        | **Действие:** кнопка удаления в шапке выбора или пункт «удалить» контекстного меню (см. «Контекстное меню сообщения» → п. 5).<br><span style="color:#0f766e">**Показываем:**</span> диалог подтверждения с числом удаляемых сообщений и переключателем «Удалить у <имя собеседника>» (включён по умолчанию). |
| 6   | Удаление у всех        | **Когда:** переключатель включён.<br><span style="color:#2563eb">**Метод:**</span> [delete-branch-commits](../method/commit/delete-branch-commits.md) (см. «Данные и методы» → п. 16).<br><span style="color:#15803d">**Результат:**</span> сообщения удаляются у обоих участников, выбор сбрасывается. |
| 7   | Удаление у себя        | **Когда:** переключатель выключен.<br><span style="color:#2563eb">**Метод:**</span> [hide-commits](../method/commit/hide-commits.md) (см. «Данные и методы» → п. 15).<br><span style="color:#15803d">**Результат:**</span> сообщения пропадают только у текущего пользователя, у собеседника остаются; выбор сбрасывается. |
| 8   | Ошибка удаления        | <span style="color:#b91c1c">**Ошибка:**</span> snackbar «Не удалось удалить»; режим выбора остаётся активным.                                                                                                                                                                              |

### Merge request

|     | **Requirement**     | **Description**                                                                                                                                                                                                                                                  |
| --- | ------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 1   | Статусы             | <span style="color:#0f766e">**Статус merge request:**</span><br>* отсутствует — merge request не открыт, кнопка предлагает открыть;<br>* `open` — открыт, идёт сбор одобрений;<br>* `readyToMerge` — одобрен всеми участниками, доступна финализация;<br>* `merged` — слияние завершено, статус финальный. |
| 2   | Доступность действий | Действия с merge request доступны участникам ветки. Защита от повторного запуска: пока операция выполняется, показывается индикатор, повторное действие не запускает её второй раз.                                                                              |
| 3   | Открыть             | **Когда:** merge request отсутствует.<br>**Действие:** нажатие кнопки → открытие (см. «Данные и методы» → п. 10).<br><span style="color:#b91c1c">**Ошибка:**</span> snackbar «Не удалось открыть merge request».                                                  |
| 4   | Одобрить            | **Когда:** статус `open` или `readyToMerge` и пользователь ещё не одобрил.<br>**Действие:** одобрить (см. «Данные и методы» → п. 11).<br><span style="color:#b91c1c">**Ошибка:**</span> snackbar «Не удалось одобрить мердж».                                      |
| 5   | Отозвать одобрение  | **Когда:** статус `open` или `readyToMerge` и пользователь уже одобрил.<br>**Действие:** отозвать одобрение (см. «Данные и методы» → п. 12).<br><span style="color:#b91c1c">**Ошибка:**</span> snackbar «Не удалось отозвать одобрение».                           |
| 6   | Отменить            | **Когда:** статус `open` или `readyToMerge`.<br>**Действие:** отменить merge request (см. «Данные и методы» → п. 13).<br><span style="color:#b91c1c">**Ошибка:**</span> snackbar «Не удалось отменить merge request».                                             |
| 7   | Финализировать      | **Когда:** статус `readyToMerge`.<br>**Действие:** завершить слияние (см. «Данные и методы» → п. 14).<br><span style="color:#b91c1c">**Ошибка:**</span> snackbar «Не удалось завершить мердж».                                                                    |

### Карточка merge request

|     | **Requirement**     | **Description**                                                                                                                                                                                          |
| --- | ------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 1   | Открытие карточки   | **Действие:** нажатие на кнопку merge request (кроме статуса `merged`).<br>**Показываем:** карточку с составом одобрений и действиями.                                                                    |
| 2   | Состав карточки     | <span style="color:#0f766e">**Показываем:**</span><br>1. участников ветки с отметкой «одобрил / не одобрил»<br>2. счётчик «одобрили N из M»<br>3. кнопку «одобрить» либо «отозвать одобрение» (по своему статусу)<br>4. кнопку «смерджить» при статусе `readyToMerge`<br>5. кнопку отмены merge request<br>6. имя инициатора |

### Заморозка ветки

|     | **Requirement**     | **Description**                                                                                                                                                                          |
| --- | ------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 1   | Активный merge request | **Когда:** статус `open` или `readyToMerge`.<br>**Поведение:** поле ввода скрыто, вместо него — «Ветка заблокирована, пока открыт merge request»; отправка недоступна.                  |
| 2   | Смерджена           | **Когда:** статус `merged`.<br>**Поведение:** ветка в режиме только чтения — «Эта ветка смерджена (только чтение)»; отправка и действия merge request недоступны.                         |

# Predictive back — акты анимации

Общий язык для обсуждения анимации жеста «назад» (predictive back). Позволяет точно
указывать, на каком этапе анимации есть проблема, а где всё хорошо: «Акт 2 — ок»,
«Акт 3a — переход слишком резкий».

Реализация: [`PredictiveNodeHost.kt`](../../core/routing/src/main/kotlin/ru/sla/clarify/core/routing/PredictiveNodeHost.kt).
Референс поведения — системные настройки Android (full-screen surface cross-fade).

**Термины:**
- **Верхний экран** — текущий экран, с которого уходим (active).
- **Нижний экран** — экран, на который возвращаемся (ближайший предок в стеке).
- **scrim** — затемняющий слой поверх нижнего экрана.

> На **root-экране** приложения собственных актов нет: жест отдаётся системе, и ОС
> рисует свою анимацию back-to-home (выход в лаунчер).

---

## Схема

```
Акт 0 (покой)
   │  палец коснулся края
   ▼
Акт 1 (касание / отрыв)
   │  палец двигается
   ▼
Акт 2 (протяжка / превью) ──── туда-сюда, обратимо ────┐
   │  отпустил                                          │
   ▼                                                    │
Акт 3 (решение) ── 3a коммит ──► Акт 4 (посадка → новый экран)
                └─ 3b отмена  ──► Акт 0 (тот же экран)
```

---

## Акт 0 — Покой
Обычный экран, жеста нет. Один слой, без трансформаций.

## Акт 1 — Касание / отрыв *(touch down)*
- **Триггер:** палец коснулся края, back-жест начался.
- **Верхний:** «отрывается» — появляется скругление углов, самое начальное лёгкое уменьшение.
- **Нижний:** проявляется под верхним, сразу под затемнением (scrim).
- **Код:** `gestureActive=true`, `progress≈0`, `commitFade=0`.

## Акт 2 — Протяжка / превью *(drag / scrub)*
- **Триггер:** палец двигается (прогресс растёт и падает, можно водить туда-сюда).
- **Верхний:** только `scale` по пальцу (1 → 0.9) + скругление + лёгкое **следование за пальцем** (сдвиг к краю свайпа по горизонтали и за `touchY` по вертикали). **Полностью непрозрачный.**
- **Нижний:** `scale` **синхронен с верхним** (оба ужимаются 1→0.9 по пальцу), но **смещён фиксированно за экран влево**. Во время drag он НЕ выезжает — стоит смещённым под **постоянным** scrim. Следует за `touchY`. Выныривание — только на коммите (Акт 3a).

> **Без зеркальности:** анимация всегда играется как свайп справа→влево (верхний уезжает вправо, нижний выныривает слева), независимо от того, с какого края реально начат жест.
- **Код:** `progress = f(палец)`, `commitFade = 0`.
- **Полностью обратимо** — это «превью назначения».

## Акт 3 — Решение *(release)* — развилка

### 3a — Коммит (принято)
Отпустил за порогом.
- **Верхний:** `alpha → 0` (уходит фейдом).
- **Нижний выныривает (только теперь!):** `scale → 1` и сдвиг → 0 (выезжает к центру на full); scrim снимается.
- **Навигация:** шлётся `Event.Back`, активный экран меняется на нижний.
- **Код:** `commitFade 0 → 1` (+ `progress → 1`), затем `onCommitBack()`. **Необратимо.**

### 3b — Отмена (отклонено)
Вернул палец / отпустил до порога.
- **Верхний** возвращается на full (`scale → 1`, скругление → 0, сдвиг → 0); scrim/нижний убираются.
- **Навигации нет.**
- **Код:** `progress → 0`, `gestureActive = false`.

## Акт 4 — Посадка *(settle)*
- После **3a:** нижний экран встал на full, верхний исчез, новый экран активен.
- После **3b:** вернулись в Акт 0 на исходном экране.

## Параметры (что чем управляется)

| Что | Акт 1–2 (drag) | Акт 3a (commit) | Акт 3b (cancel) | Параметр в коде |
|-----|----------------|------------------|------------------|-----------------|
| Scale верхнего | 1 → 0.9 по пальцу | дожимается до 0.9 | → 1 | `progress` → `TOP_MIN_SCALE` |
| Сдвиг верхнего по гориз. | вправо (всегда, без зеркальности) | дожимается | → 0 | `topShiftPx` |
| Сдвиг верхнего по верт. | следует за пальцем (`touchY`) | удерживается | → 0 | `verticalFraction` × `topShiftYPx` |
| Скругление верхнего | растёт по пальцу | — | → 0 | `MAX_CORNER_DP` |
| Alpha верхнего | **1 (без изменений)** | 1 → 0 | 1 | `commitFade` |
| scrim нижнего | **постоянный ~0.8** | 0.8 → 0 | убирается | `MAX_SCRIM_ALPHA`, `commitFade` |
| Нижний scale | синхронно с верхним (1→0.9 по пальцу) | восстанавливается → 1 | возврат | `applyBelowTransform` (`scaleProgress`) |
| Нижний сдвиг | фиксированно за экран влево | выезжает к центру (по `commitFade`) | возврат | `belowShiftXPx`, `commitFade` |

**Ключевой принцип:** во время протяжки (Акт 2) меняется **только `scale`** верхнего.
`alpha` верхнего и снятие scrim происходят **только** на коммите (Акт 3a). За это отвечают
два независимых прогресса: `progress` (drag) и `commitFade` (commit).

Текущие значения: `TOP_MIN_SCALE=0.9`, `MAX_SCRIM_ALPHA=0.8`, `MAX_CORNER_DP=32`,
`COMMIT_ANIM_MS=250`, `CANCEL_ANIM_MS=220`.

## Статус по актам

Заполняется по ходу ревью (✅ ок · ⚠️ есть замечание · ❓ не проверено).

| Акт | Статус | Заметки |
|-----|--------|---------|
| 0 — Покой | ✅ | |
| 1 — Касание / отрыв | ✅ | направление сдвига исправлено — к краю свайпа, отрыв с противоположной стороны |
| 2 — Протяжка | ✅ | scale/fade разделены; follow за пальцем по Y; нижний — синхронный scale + смещён за экран, выныривает на коммите |
| 3a — Коммит | ✅ | мелькание уходящего экрана на hand-off убрано: причина — прозрачный экран-назначения (ChatList без фона), сквозь дыры которого просвечивал ещё непрозрачный уходящий экран. Фикс — непрозрачный фон у экрана-назначения (как у всех через `ScreenScaffold`) |
| 3b — Отмена | ❓ | |
| 4 — Посадка | ✅ | после упрощения (убран битмап/z-index) откат чистый — посадка без артефактов |

## Раскатка на экраны (M5)

Паттерн: убрать **безусловный** `BackHandler(onBack = navigateBack)`, чтобы жест
дошёл до `PredictiveNodeHost` (он сам шлёт `Event.Back` через `onCommitBack`).
Условные `BackHandler` (оверлеи/режимы) — оставить.

Перед удалением проверено, что `navigateBack` каждого экрана эквивалентен дефолтному
`Event.Back` (для flow-узла — `Finish(dismissResult)`, для вложенного экрана — pop к
родителю):

| Экран | `Event.Back` по умолчанию | `navigateBack` | Статус |
|-------|---------------------------|----------------|--------|
| ChatList ↔ Thread (direct) | — | — | ✅ прототип |
| GroupThread | `Finish(Dismissed)` | `GroupThreadDismissed → Finish(Dismissed)` | ✅ убран |
| GroupInfo | pop → `main` | `GroupInfoDismissed → NavigateTo(main)` | ✅ убран + обёрнут в `ScreenScaffold` (непрозрачный фон) |
| Profile | `Finish(Dismissed)` | `ProfileDismissed → Finish(Dismissed)` | ✅ убран |
| Branch | `Finish(Unit)` | `BranchDismissed → Finish(Unit)` | ✅ убран (условный BackHandler merge-request оставлен) |
